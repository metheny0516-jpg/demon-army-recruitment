## 0. v1 で外したこと、v2 で変えたこと

v1 のオーナー評価は **「ボタンをぽちぽちするだけ」「何のゲーム性もない」「分岐する小説系」**。
続けて **「採用がメインなのに、そこの判断が弱い／強調されてないから、適当にすすめちゃう」**。

原因は動的要素の不足ではなく、次の二つだと判断した。

1. **賭けが無かった。** 相手の条件をプレイヤーが選んでいた（`?cond=B`）ので、
   酒を出せば必ず飲む。当たり前の結果に感情は動かない。
2. **採用が判断になっていなかった。** 固定の応募者一覧から予算内で足し算するだけ。
   読まずに進められる形になっていた。

v2 で変えたのは次の五つ。CHAIN も新しい戦闘機構も足していない。

| 変更 | 何のためか |
|---|---|
| **面接形式**。応募者が一人ずつ来て、その場で採るか見送るかを答える。**戻れない** | 採用を飛ばせなくする |
| 履歴書を **確かなこと／本人の申告／未確認** の三段に分け、未確認の一文で賭けさせる | 読む理由を作る |
| **隠れた性質**。働かせて初めて分かる。判明すると必ず数値か能力が動く | 採用の答え合わせを作る |
| **相手の条件を隠して毎ラン抽選**。酒が通るかは事前に分からない | 店に人を割く判断を賭けにする |
| 応募者を毎ラン抽選、予算6G・枠3、近郊警戒は生還84%の博打、ラン記録が残る | 「次はあいつを」の材料を作る |

## 2. 試し方

**3回続けて遊んでほしい。** 1回2〜3分。2回目以降に面接画面へ前のランの記録が出る。

1. **面接（6人）**。一人ずつ来る。「未確認」の一文だけが手掛かり。採るか見送るか答える。
   予算6G、追加で採れるのは最大3人。全員は採れない。
2. **配属**。守備／門番／城下の店／近郊警戒。
   酒を造れるかは**本人の能力**で、店に置いただけでは造れない。
   近郊警戒は生きて帰れば昇進するが、**帰らないこともある**。
3. **任せて進める**（3回）。勤務 → 城下 → 到着。
4. **迎撃**。選んだ順が並び順。先頭が狙われやすい。
5. **答え合わせ**。隠れていた相手の条件と、採った人の隠れた性質が明かされる。

### 読みどころの例（`?seed=42`）

グドという**ゾンビの元厨房**が2Gで来る。能力欄はただの前衛。
未確認の一文は「宿場の厨房、と書いてある。**宿場には酒も出る。**」
ここを読んで採り、城下の店に置くと——**実は酒が造れる**。

ボルという荷運びが1Gで来る。「隊商が三度襲われて、三度とも荷を守り切っている。」
採って戦わせると、見た目より打たれ強い。

ドルドという傭兵は4Gで、数値は一番強い。「どの戦場も、在籍が三月より短い。」
採って戦わせると、**見た目ほど保たない**。

手掛かりは必ずその性質に対応した本当の情報にしてある。嘘の手掛かりは書いていない。
ただし一文だけでは断定できない書き方にしてある。

## 3. 実装で決めたこと

- 状態は `src/prototype/hero_arrival_world.js`（DOM非依存・Nodeから読める）だけが持つ。
- 戦闘は既存 `Battle.simulate` をそのまま呼ぶ。試作用の戦闘計算は足していない。
- 起きたことは全部 `facts` 台帳に積む。報告文も敵情への反映も台帳からしか作らない。
  だから事実と食い違う報告が構造的に出せない。
- 人物名で分岐する条件を書かない。酔いの反映も「`consume` が付いたID」を引くだけで、
  アレンという名前を見ていない。
- 隠れた性質は**採用した時点で効き始める**が、判明するまで画面には申告値しか出さない。
- 採らなかった人の中身は明かさない（総当たりで確定させる手段を作らない）。
- 一マス移動、T管理、集合操作は作っていない。

## 4. 測ったこと（`node tools/sim-hero-arrival.js 300`）

予算6G・枠3で**実際に組める**編成だけを比べている。

| 編成 | 勝率 | 戦没 |
|---|---|---|
| 安く5人そろえる（3G） | 83% | 2.8人 |
| 安く5人＋火力1枚（5G） | 96% | 2.0人 |
| 4人で火力に寄せる（6G） | 45% | 3.2人 |
| 追加採用なし（在籍2名のみ） | 0% | — |
| 店に1枠（モグ）＝賭けが外れた | 68% | 3.5人 |
| 店に1枠（モグ）＝新酒が通った | 77% | 3.1人 |
| 店に1枠（ドゥバ）＝蒸留酒が通った | 97% | 2.1人 |
| 店も火力も取る（6G）＝外れた／通った | 88% ／ 92% | 2.6／2.3人 |
| 近郊警戒（ガロ単独）の生還 | 84% | — |

読み方：**頭数が一番効く**（4人にすると大きく落ちる）。
酒の賭けは、軽い酒が当たりやすくて効果小（+9pt）、強い酒が当たりにくくて効果大（+29pt）。
相手の条件は 任務優先35% ／ 休憩中40% ／ 気が緩んでいる25%。
つまり軽い酒は65%で通り、強い酒は25%でしか通らない。

## 5. 未検証事項（試遊で見てほしいところ）

1. **面接が重くなりすぎていないか。** 6人を一人ずつ読むのは、まだ「ぽちぽち」か。
2. **未確認の一文が読めるか。** 手掛かりとして機能しているか、ただの飾りに見えるか。
3. **答え合わせが効くか。** 「宿場には酒も出る」を読んで当てたとき、嬉しいか。
4. **賭けが賭けに感じられるか。** 相手の条件が隠れていることが伝わっているか。
5. **近郊警戒で古参を失うのは、悔しいか理不尽か。** 84%生還は妥当か。
6. **3回遊びたくなるか。** 面接画面に出る前ランの記録は効いているか。
7. **戦闘は今のままでいいか。** 自動戦闘のまま、賭けの結果を見る場として機能しているか。
8. **見送った人の中身が分からないままなのは、気持ち悪いか良いか。**
