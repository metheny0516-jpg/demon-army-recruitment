# Gemini向け・敵剣士制作キット

まず1体の待機絵を承認し、差分を1枚ずつ作る。まだGeminiには送信していない。
ゲームの現行画像はこのキットで上書きしない。

## 最初にやること

1. Geminiへ `reference-swordsman.webp` を添付する。
2. `01-idle.md` のコードブロック内を貼り付け、待機絵1枚だけ生成する。
3. ダウンロードした元画像をこのタスクへ返す。スクリーンショットではなくPNG原本が望ましい。
4. 待機絵の画風・輪郭・装備・透過を確認してから、下の差分へ進む。

## 承認後の順序と保存名

|---|---|---|

生成を繰り返すほど別人にならないよう、差分にも必ずidle原本を添付する。
ファイル名を画像内へ印字させない。依頼文は各ファイル単独でも使える。

## 合格基準

- 全6枚が同じ人物、衣服、装備、持ち手、カメラ角度。素材は右向き（敵配置時はゲーム側で反転）。
- 1024角を希望。別寸法で出力された場合も無理に引き伸ばさず原本を返す。
- 全身と剣先が欠けない。ポーズごとに身体寸法が膨らまない。
- 背景は実alpha透明。見た目のチェック柄だけでは合格としない。
- 透明PNGが得られない場合は、その事実と原本を返す。何度も同じ指示で量産しない。
- 100〜140px表示でも溜め／攻撃／被弾を区別できる。

## 受け取り後の担当（Codex）

未承認素材は本番と分離して保管し、alpha・余白・身体寸法を検査。
6枚を共通倍率・足元で512角WebPへ整え、既存swordsmanのポーズ登録を拡張する。
個別に最大フィットさせると大きさが跳ねるため行わない。
現行のシート分割スクリプトを単体PNGへそのまま適用しない。
近接38%命中・総尺・倍速・低モーション・skip・画像失敗時の表示を検証してから採用する。

弓兵・敵魔法使いは剣士の動作確認後。今回のキットは剣士のみ。
設計ゲート7: 敵の攻撃の予備動作と被弾を短時間で見分けられることを狙う。
モンスター画像スキルの画風を継承し、オーナー指定に従って履歴書ではなく戦闘専用全身絵にする。
