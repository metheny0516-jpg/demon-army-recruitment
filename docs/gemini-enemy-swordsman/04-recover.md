# 攻撃から戻る

以下をGeminiへ貼り付けてください。

```text
2D RPGの戦闘用全身スプライトを1枚だけ制作してください。複数ポーズのシートや比較図は不要です。

添付の基準画像と同じ人物・画風・装備を維持してください。鉄の丸兜、茶髪、青いマフラーと青い上着、生成りのズボン、茶色の革手袋とブーツ、片手の短剣と反対の手の木製丸盾。兜や剣の形、盾の大きさ、持つ手、体格、頭身、色を変えないこと。若く少し緊張した見習い兵で、英雄のように美化しないでください。

太く少し不均一な輪郭、抑えた色、控えめなセル塗り。90年代の卓上RPG図鑑とスーパーファミコンのモンスター図鑑の雰囲気。3D・光沢・強い逆光・派手な装飾は禁止。

出力は1024×1024のPNG。実際のアルファ透明背景にしてください。チェック柄を背景として描かないこと。背景、床、影、煙、光、斬撃、文字、ラベル、枠、UI、透かしは描かないこと。

右向きの横向き寄り3/4視点。カメラ角度を固定し、左右反転しないこと。全身・剣先・盾・マフラーを切らず、四辺に最低80pxの余白。立っているポーズの接地位置はy=920px付近、人物の中心はx=512px付近。同じ身体寸法を維持し、ポーズごとに拡大して枠を埋めないこと。倒れるポーズも同じ身体寸法・接地位置を維持。横移動や跳躍はゲーム側で付けるため、人物を画面端へ移動しないこと。

添付の承認済みidle.pngを人物・画風基準、strike.pngを動作の直前の参考として使用。振り抜いた腕を引き戻し始め、剣先を下げつつ盾を胸の前へ戻す。前脚にまだ少し体重があり、上半身を起こす途中。攻撃姿と待機姿の中間で、待機絵の単純コピーにしない。
```
