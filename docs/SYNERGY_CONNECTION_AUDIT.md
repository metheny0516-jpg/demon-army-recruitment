# シナジー接続監査

更新日: 2026-09-02

この文書は、現行実装を「シナジー発見・連鎖・壊れビルド形成」へ移行するための差分台帳である。
設計思想は `GAME_DESIGN_PRINCIPLES.md`、現在遊べる仕様は `README.md` を正本とする。

## 1. 監査基準

各要素を次の観点で判定する。

- **入口**: プレイヤーが組み合わせの仮説を立てられるか
- **発火**: 明確なイベントや状態変化を条件に動くか
- **生成**: 別能力が反応できるイベント、資源、状態を作るか
- **再発火**: 効果が別能力を呼び、連鎖を伸ばせるか
- **方向転換**: ラン途中で採用・配置・施設選択を変えたくなるか
- **可視化**: なぜ起きたか、誰が起点かを理解できるか

単純加算そのものは廃止しない。ただし、入口や補助として使い、行き止まりの完成形にしない。

## 3. 競合の処理

### 三部門を拡張軸にする方針

三部門そのものは維持するが、個別の生産効率、専用画面、専用資源を増やす方向は停止する。
配属は「誰をどこで働かせるか」から「どの発火条件を作るか」へ意味を変える。

### 食料不足を避ける方針

不足による忠誠低下は残す。ただし、食料0や大量消費を狙う能力を加え、安全維持だけを正解にしない。

### 建設が弱いと成長が止まる方針

一律の足切りは廃止する。施設はビルド方向を大きく変える選択物にし、建設を使わないルートにも
別の代償と強みを持たせる。

### シナジー条件を完全非公開にする方針

具体的な未発見効果は隠してよい。ただし履歴書では反応対象、編成画面では発火予告や不足条件を示し、
総当たりではなく仮説から発見できるようにする。

### 壊れビルドのバランス

勝率差だけで弱体化しない。毎ラン同じ手順で再現できるか、単純加算が他の判断を消しているか、
演出と因果が理解できるかを先に確認する。

## 4. 最初に縦に完成させる3系統

### A. 略奪経済

`攻撃 → 略奪 → 金貨獲得 → 強欲が反応 → 追加行動 → OVERKILL → 追加略奪`

既存のゴブリン、給与、略奪作戦、所持金を利用できる。ゴブリン軍団の単純倍率を最初に変換する候補。

### B. 暴食・飢餓

`食料消費 → 大食漢／料理人が反応 → 一時強化 → 食料0 → 飢餓能力発火 → 追加行動または全軍強化`

既存の `appetite`、食料調達、食料不足、食事不要体質を利用する。食料を維持作業からビルド資源へ変える。

### C. 戦死・蘇生

`味方死亡 → 墓地／死霊術師が反応 → 蘇生または召喚 → アンデッド増加 → 死の軍勢強化 → 再度死亡`

既存の永久退場、蘇生、供養代行、死の軍勢を利用できる。損失と利益が同居する本作らしい代表系統。

## 5. 共通連鎖基盤に必要な最小語彙

最初から万能DSLを作らない。代表3系統に必要な次だけを扱う。

- 発火イベント: 攻撃、撃破、死亡、蘇生、召喚、資源獲得、資源消費、資源0、OVERKILL
- 発火主体と原因
- 対象
- 生成量または変化量
- 連鎖深度とCHAIN番号
- 1行動・1戦闘ごとの発火上限
- 同一能力から同一能力への再入禁止または回数制限
- 戦闘タイムラインへの因果記録

## 7. 当面停止する拡張

- 新しい部門値、専用資源、管理画面の追加
- 人数条件＋倍率だけの新シナジー量産
- 施設の単純なHP・防御加算の積み増し
- 2Dキャラクター量産
- モルモ男女差分の制作
- 装備システムの先行実装
- 敵編成やイベント数だけを増やす拡張

これらは廃止ではない。代表3系統で「発見 → 連鎖 → 壊れ → 可視化」が成立した後に再評価する。
