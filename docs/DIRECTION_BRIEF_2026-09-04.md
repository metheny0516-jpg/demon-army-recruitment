## 1. このセッションで変わったこと（すべて実測付き）

### 食料経済（ae85963 / 8863cd5 / 3223116 / 5fa1184）

**変更前の実測**: ほぼ全ランが3〜9戦目に食料不足へ落ち、**以後の完全回復は0〜3%**。
一方「不足したら戦闘力の低い者を生活部門へ回す」だけで**クリア率27%→76%**。
解法は一手で存在するのに、判断材料が画面に出ていなかっただけだった。

- 収支（調達/消費）をHUD・応募者カード・編成画面へ常時表示。単位を統一（3口＝食料1）
- 備蓄上限 `foodCapacity()`（消費×4・最低8）。超過分は決算時に腐る
- 宴 `holdFeast()`。食料を消費して食う者の忠誠+6と与ダメージ+15%（次の1戦）
- 飢餓適応 `starved`。3戦耐えた者は食料を消費しなくなる（代償: 最大HP-15%）
- 食わない者は飢えても忠誠が下がらない

**重要な失敗記録**: 備蓄上限を入れる前は宴が明確な罠だった（27%→20%）。
余剰が「不足への保険」として無限に価値を持っていたため。
**食料を消費する要素は、必ず上限とセットでないと成立しない。**

### シナジーの排他性（57a4748 / 04c7374）

**変更前の実測**: 戦闘あたりの同時シナジーは平均0.07〜0.54、**最大2**。
7〜8割の戦闘が最大CHAIN深度2（攻撃→死亡）で終わっていた。

原因は倍率ではなく構造。シナジー8個の大半が「同種3体」で、出撃5枠を奪い合う。
ゴブリン3体と魔法職3体は5枠に同居できず、**組み合わせが原理的に成立しなかった**。

- 発火条件を数える母集団（軍団全体）と効果対象（出撃した者）を分離
- meta型シナジー《魔王軍完成》。2つ以上同時発動で発動数-1につき全員+20%
- 指名求人。6要項・中盤解禁・求人費6G倍々。条件はシナジーの発火条件と同じ語彙

同時シナジーは最大2→**最大5**へ。

### 連鎖と演出（2d3b9c1 / 9fe8ccd / 05b847c / 8714ff3 / 764f2c2）

オーナー指摘「連鎖が爆発に見えない、ふつうの戦闘が淡々と行われているようにしか見えない」。
**原因は演出ではなく数字だった。**

1. 伝播ダメージが「余剰×0.22」固定で、余剰は撃破のたびに小さくなる。
   つまり**段が進むほど威力が落ちていた**。演出だけ盛り上げても淡々に見えて当然
2. OVERKILLには見返りが無かった。「ボーナスを明示」しようにも中身が存在しなかった

- 伝播倍率を段で伸ばす（35% → 60% → 85%）
- **戦意（momentum）**を追加。余剰を出すほど与ダメージ倍率が積み上がる（上限×2.2）。
  `momentum` イベントを戦闘タイムラインへ追加（**契約の追加**）
- 戦意メーターを戦場へ常設、連鎖の段と戦意でダメージ数字を最大2.2倍に拡大
- 全画面演出（《魔王軍完成》とOVERKILL100%以上のみ）、積み上がるCHAINカウンタ、伝播の稲妻

**実測（同じ出撃メンバーで軍団だけ変えて60戦×4条件）**:
シナジーなし0% / 1つ0% / **2つ18%** / **3つ20%**（深度4以上の連鎖が起きた割合）。
必要余剰率を下げる前は 0/0/7/10% だった。**深さの上限だけ上げても伸びない。**

## 2. 現在のバランス（sim 200ラン）

クリア率 **12.5%〜52.5%**。目安は5〜50%。

経営が回る2戦略（三部門均衡・未払い搾取）が50%をわずかに超える。
ただし戦意や《魔王軍完成》の刻みを下げても同水準のままなので、
**これらの機能が原因ではなく食料改修由来の水準**である。実行間分散は±6ptある。

**simの読み方の注意**（過去のレビューが誤認した点）:
- 通常給与・施設選択・部門配置は**大部分が固定ロジック**。人間の判断の実測として扱わないこと
- simの戦略はシナジーを狙わないので、同時シナジー数とCHAIN深度を過小評価する
- 求人は無限無料ではない。無料枠のあと広告費が倍々に増える

## 3. 未決の論点

### A. 敗北の継承（ロマサガ2式）— オーナー選択済み・未着手
「全滅したらパーティを組み直し、他の進行度は維持」。
**オーナーの選択は「敵は強いまま、継承で追いつく」**。
現状は「再起＝巻き戻し」と「代替わり＝全リセット」の2つしかなく、継承はその中間の新しい層。
維持するもの: 王国攻略度・施設・魔界史・発見済みシナジー。失うもの: 軍団全員。
追いつかせる手段（前代の将軍の能力を継ぐ等）が設計の核心で、未確定。

### B. 連鎖の尺
設計憲法 第3節で「CHAINは縮めず、大きさに応じて伸ばす」と決めてあり、
いまは1段ごとに最大+50%長くなる。6段の連鎖だと間延びする可能性がある。
「中盤の段は畳み掛けて最後で止める」方向は憲法の方針変更にあたる。

### C. シナジーの母数
8個のまま。排他性は壊してあるので、個数を増やせば素直に効く。data層（CodeX）。

### D. 新しいモンスター
サキュバス・ミノタウロス・ドラゴンなど。指名求人に「ビジュアル重視」を足すには
テンプレ側に見た目の属性が要る（現状は無い）。data層（CodeX）。

## 4. 制約（レビュー時に前提として踏まえるべきこと）

- **層で分ける**: `assets/` `src/data/` はCodeX、`src/core/` `tools/` はClaude、`src/ui/` は両方
- **`src/core/run.js` と `src/core/battle.js` は同時に触らない**（分担ルール3）
- **2026-09-04時点でCodeXが `battle.js` `battle_scene.js` `styles.css` に入っている**。
  戦闘と演出の層は現在CodeXの持ち場
- 効果音は**外部素材のみ**。自作合成音は何度も失敗しているためオーナーが禁止。
  物理打撃は AntumDeluge thwack 08/09 で選定済み（再選定不要）
- 恒久成長を単純な数値上昇にしない。増やすのは選択肢・組み合わせ・発見・歴史
- コンテンツ数より**既存要素との接続数**で評価する
