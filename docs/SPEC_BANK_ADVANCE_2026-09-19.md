# 仕様：魔界銀行の前借り ― 誰を賭けるかで、いくら借りられるかが変わる（2026-09-19、Opus）

バックログ（HANDOFF）：「いま 20G、3決着後に 30G 返す。返せなければ取り立て人が城へ来る（防衛戦の一種）か、
担保の部下を連れていかれる（名簿から消え、蔵に借用書）。**利子・税率の管理は増やさない。**
接続先は防衛戦・戦死／離脱・蔵・事件。**今の銀行の置き換え候補**」。

## 0. 一文で

**借りるときに「誰を担保に出すか」を決める。その人物の戦功で借りられる額が決まり、期限までに返せなければ
本人が連れて行かれる。** 利子の管理は消え、残るのは「この3決着で 30G 作れるか」という一手の賭けだけ。

## 1. なぜこの形か（15節の10の問い）

1. **新しい判断か** → はい。「いくら要るか」ではなく「**誰を賭けるか**」。強い者を賭ければ大きく借りられ、
   失うときも大きい。弱い者なら小口だが安全。金の判断が人物の判断になる。
2. **新しい組み合わせが生まれるか** → はい。戦功＝階級＝出撃の主力なので、**担保に出した者ほど出したくない**。
   「出せば返せるが、死ねば代わりを立てられない」が毎決着に効く。遺物持ち・二つ名持ちを賭けると重みが増す。
3. **発見できるか** → はい。期限切れの取り立てを1回踏めば「借りるとはこういうことか」が分かる。説明は要らない。
4. **プレイごとの差** → はい。担保にした人物が誰か、返せたか、踏み倒したかでランの歴史が変わる。
5. **もう1回遊びたい理由** → 「次は将軍を賭けて大口を借り、一気に城下町を建てる」が成立する。
6. **人に話したくなる事件** → 「ゴルドを担保に 50G 借りて、返せなくて連れて行かれた。蔵に借用書だけ残った」。
7. **画面で伝わるか** → 担保の札に⛓が付き、期限が「あと2決着」と出る。見ただけで分かる。
8. **作業量が増えるだけでは** → いいえ。**利子の毎決着処理を捨てる**ので、むしろ管理は減る（下の 2-6）。
9. **他へ接続するか** → 防衛戦（取り立て人）・戦死／離脱（担保が消える）・蔵（借用書）・噂の札（door B）。
10. **まだ知らない壊れ方への期待** → 「将軍を賭けて借り、その将軍で勝って返す」が回り出すと、
    借金が攻めの手になる。踏み倒しも道として残す（下の 2-5）。

## 2. 仕組み

### 2-1. 借りる（作戦会議の前、城下町の銀行）

借入は **金額と期限と返済額が最初から確定した1枚の契約**。利子の残高管理は無い。

| 口 | 受け取る | 返す | 期限 | 担保に要る戦功 |
|---|---|---|---|---|
| 小口 | 15G | 20G | 3決着後 | 0（誰でも） |
| 中口 | 30G | 45G | 4決着後 | 10 |
| 大口 | 50G | 80G | 5決着後 | 25 |

- **担保は名簿から1人を指名する（必須）。** その者の戦功が表の値以上でないとその口は選べない。
- 同時に持てる契約は **1つだけ**。返すか片付くまで次は借りられない。
- 期限は**決着の回数**で数える（訓練・力試しも1決着として数える＝逃げ場を作らない）。

### 2-2. 担保に出した者（`m.collateral = true`）

- 今までどおり働く。出撃も留守番もできる。**能力は変わらない。**
- 名簿・編成・戦場の札に **⛓** が付き、「担保（あと N 決着）」と出る。
- **担保の者が戦死・離脱したら**、契約は消えない。次の決着の頭に銀行が代わりを要求する
  （名簿から1人を指名し直す。指名できる者が居なければ期限切れと同じ扱い＝2-3）。

### 2-3. 期限が来たとき

決着の処理の中で判定する。**返済額を払えるなら黙って払う**（所持金から引き、契約は終わる。日誌に1行）。

払えないとき、プレイヤーが選ぶ（モルモの全画面。既存の `App.report` + `choices`）：

| 選択 | 起きること |
|---|---|
| **連れて行かせる** | 担保の者が名簿から消える。契約は帳消し。**蔵に借用書が残る**（遺物枠に1品。効果は無く、魔界史に名前が残る） |
| **待ってもらう** | 次の決着で **取り立て人が城へ来る**（防衛戦の一種）。勝てば契約は帳消し、負ければ担保の者を連れて行かれたうえ、蔵から1品持って行かれる |

- **取り立て人**は既存の防衛戦の経路（`counterattack`）に乗せる。隊列は王国ではなく銀行の私兵
  （`ENEMY_STAGES` の中盤から引き、`rebelLook` と同じ要領で姿だけ差し替える）。新しい戦闘系統は作らない。
- どちらを選んでも**ランは終わらない**。失うのは人と品であって、ゲームオーバーではない。

### 2-4. 早く返す

期限前でもいつでも返せる（返済額は確定なので割引は無い）。返した時点で担保は外れる。

### 2-5. 踏み倒し（意図的に残す道）

弱い者を担保に小口を借り、連れて行かせて踏み倒すのは**成立してよい**（第7節「既知の強い手順の再現は許す」）。
ただし一度踏み倒すと **`st.town.credit = false`** になり、**そのランではもう借りられない**。
数字の信用度は作らない（管理を増やさないため）。2値だけ。

### 2-6. 今の銀行は置き換える

- `TOWN_RULES.bank`（`choices: [10,20,30]` / `cap: 50` / `interest: 0.1`）→ `advances`（上の表）へ。
- `Town.interest()` と、決着ごとの利子処理・**施設の差し押さえは削除**する。
  （＝毎決着の管理が1つ減る。オーナーの「利子・税率の管理は増やさない」はこれで満たす）
- 旧セーブに `t.debt > 0` が残っていたら、`migrateState` で **帳消しにして日誌に1行**
  （「銀行が帳簿を書き換えた。前の借金は無かったことになっている」）。残高を契約へ変換はしない。

## 3. 状態

```js
st.town.advance = {            // 契約は同時に1つ。無ければ null
  id: "small" | "mid" | "large",
  gold: 15, repay: 20,         // 受け取った額と返す額（確定）
  settlesLeft: 3,              // 決着ごとに -1
  uid: 41,                     // 担保の者
  overdue: false               // 「待ってもらう」を選んだ（次の決着で取り立て人）
};
st.town.credit = true;         // 踏み倒すと false（そのランは借りられない）
```

- `m.collateral` は持たせない。**担保かどうかは `st.town.advance.uid` と突き合わせて出す**（状態を二重に持たない）。
- 魔界史（`record`）に `advance: { borrowed, repaid, seized }` を残す（借りた回数・返した回数・連れて行かれた回数）。

## 5. 文（統括が書く。実装はそのまま入れる）

- 借りるとき：「担保はどなたにしますか。……ええ、そういう商売でして」
- 期限の前の決着：「銀行から催促状デス。あと{N}決着で {repay}G」
- 払えたとき：「完済デス。銀行員が少し残念そうでした」
- 期限切れの選択：「払えません。……どちらにいたしますか」
- 連れて行かれた：「{name}は、笑って手を振って行きました。蔵に借用書が残っています」
- 取り立て人：「銀行の私兵が門の前デス。話し合いは済んだそうデス」

## 6. 数で見る（sim / econ-trace）

- `econ-trace` に「借りない／小口を毎回／大口を1回」の3本。見るのは**終了時の所持金**と**城下町 Lv 計**。
- 狙い：**小口を毎回借りる**が「借りない」より強くならないこと（借金が常に最適解になると判断が消える）。
  大口は「決まれば伸びる、外すと痛い」＝分散が大きい形にする。
- 外れたら動かすのは**返済額**（20/45/80）だけ。受取額と期限は動かさない（判断の形を変えないため）。

## 7. やらないこと

- 利子・信用度の**数値**管理（2値の `credit` だけ）。
- 複数の契約の同時進行。
- 借金でゲームオーバーにすること。失うのは人と品まで。
- 取り立て人の専用データ（既存の段階表を借りて姿だけ変える）。

## 未決（既定で進めてよい）

- U1 担保の者が**魔王本人格の将軍1体しか居ない**とき → 既定：その者を担保にできる（縛りを作らない）。
- U2 取り立て人に勝った後 → 既定：契約は帳消し。**借用書は残らない**（勝ったので）。
- U3 「待ってもらう」を選んだ決着に、王国の反撃も予約されていたら → 既定：**王国が先**。取り立ては次の決着へずれる。
- U4 踏み倒した後に力試しや第三幕へ行ったとき → 既定：`credit` はランを通して戻らない。
