# ゴブリン／スライム／ゾンビ 指示待ち2D回転 組み込み

## 組み込み仕様

- 対象は `goblin`、`slime`、`zombie` の3種だけ。ほかの種族は既存の `poseEnter` を維持する。
- 指示の番が初めて来た時に、予備動作 0.09秒 → 8方向 `0..7` を2周 0.275秒 → `8` の決めポーズ → 0.08秒の沈み、の順で再生する。指示入力は待たせない。
- 決めポーズ後の軽い揺れは既存の battle sprite の待機アニメーションを使う。同じ人物の狙い選び・パネル再描画では回転を再開しない。「もどる」で番が改めて来た場合は再生してよい。
- 行動決定、指示窓終了、再描画を伴う画面終了、戦闘終了では、個体トークンと既存 `stop()` で古いコマ予約と actor motion を止める。
- `prefers-reduced-motion` では従来どおり静止 `ready.webp` のみを表示する。回転コマの読込失敗時も `ready.webp` へ戻す。

## 素材制作と抽出

受領元は `motion-source/maou-three-monsters-motion` の独立試作。試作 `animation.js` の処理を
`tools/extract-ready-spin-frames.cjs` へ移植し、実行時 Canvas を使わず、各種9枚の512×512透過WebPへ事前出力した。

```sh
node tools/extract-ready-spin-frames.cjs /path/to/maou-three-monsters-motion
```

- 全atlasは1254×1254、1セル418px。
- 黒とマゼンタのクロマキー条件は試作と同一。
- ゴブリンだけ、試作どおり各セルの最大連結成分を残す。特殊crop（frame 5の高さ396px、frame 8の上20px拡張）も維持する。
- スライム frame 8だけ上へ78px拡張する。スライム／ゾンビでは水滴・手指・靴を失うため連結成分を削除しない。
- 各コマのalpha境界から横中心と足元を求め、出力上の x=256、y=480 に揃える。

素材の出典・権利は受領物の `README.md` に従う。既存絵と新規コマ絵をCC0／CC-BYとは断定せず、原作品の権利・条件を維持する。今後の画像素材制作はTerraが担当し、承認済み素材を受領した後の本編組み込みは別担当でもよい。

## Opus 最終煙試験（390px）

1. 390×844で、3種を含む部隊を編成して手動戦闘を開始する。
2. 各種の番で、通常の右向きから8方向2周、決めポーズ、軽い揺れへ移ることを目視する。足元の跳び、隣セル片、黒／マゼンタ背景が無いことも見る。
3. 回転中にも指示ボタンを押せること、押した直後に選んだ構えへ移り、古い回転が上書きしないことを確認する。
4. 敵が複数いる時に「たたかう」→狙い選び→「もどる」を操作し、単なる狙い選び再描画では再回転せず、人物へ番が戻った時だけ再回転することを確認する。
5. 回転中に戦闘を終了／画面遷移し、遅れて画像や動きが混入しないことを確認する。
6. OSの「視差効果を減らす」を有効にして、回転せず静止 `ready` になることを確認する。

自動の対象確認は `tools/browser-tests/ready-spin.js`。3種の中間コマとframe 8、同一人物の再描画、行動決定、`stop()` 後のタイマー汚染を検査する。
