# 設計案：波乱の仕掛け ― 正規ルートの上に「事故」を散りばめる（2026-09-14、Claude 起草。案。オーナー判断待ち）

オーナー：「正規統制ルートでも楽しめるよう質を上げているが、カオスな波乱の展開のための痕跡の散りばめ、魔法使いとスライムが組んだときの無限増殖事故など、ぶっとんだ展開の仕掛けを設計しておいて」。

## 0. 方針（3行）

- 事故は**規則が生む**。乱数で降ってくる不幸ではなく、「この2つを組むと起きる」と後から説明できるもの。だから狙って再現でき、語れる。
- 事故は**利益と損失が同時に出る**。得だけなら攻略法、損だけなら罰。両方あるから「波乱」。
- 事故は**痕跡を残す**。起きたことが後の面接・台詞・技・遺物に顔を出し、「あの事故のせいで／おかげで」がランの物語になる。

既にある土台：連鎖（`chain.js`、因果イベント）、シナジー10種、戦場のハプニング10種、痕跡（`Traces`）、召喚の口（`SKILL_EFFECTS` の `summon`）、城下町、遺物、殿堂。**新しい仕組みは足さず、これらの組み合わせで作る**。

## 2. 共通の規則

- **1ランに同時に起きる事故は 2 つまで**（`st.chaosActive`）。3つ目は起きない。中高生が追える量にする。
- 事故が起きたら**モルモが一言で説明**する（「魔法使いの火がスライムに……増えてます、増えてますヨ」）。仕組みの説明は決着画面の1枚だけ。
- 事故は**オフにできる**（設定「波乱：あり／なし」。sim の既定は「なし」で、比較用に「あり」の列を足す）。正規ルートで遊びたい人を邪魔しない。
- 事故の得と損は**同じ画面に並べて見せる**（「骸骨2体が入った／墓地が Lv2→1」）。
- 痕跡は `Traces.record` に `kind: "chaos"` で残し、面接の台詞（`RECRUIT_BRIEFS`）と殿堂の一行に出す。

## 3. 入れる順（案）

1. ★1 無限増殖（召喚の口があるので battle.js 側は `SKILL_EFFECTS` の hook で書ける。名簿に残す処理は run.js）。
2. ★2 骸骨の暴走（4枚目のカードの仕組みは訓練で作ったので流用できる）。
3. ★3 持ち逃げ（既存の逃亡処理に「金を持つ」「敵に出る」を足す）。
4. 残りは試遊の反応を見て2つずつ。

## 4. 触るもの（★3つぶん）

- battle.js／skill_effects.js（Claude）：増殖の hook（火球の着弾イベントを読んでスライムに `flags.dividing` を立て、ラウンド頭に `summon`）。持ち逃げ犯を敵として写す `options.bounty`。
- run.js（Opus）：分身を名簿に残す、骸骨の暴走カード、持ち逃げ（金・逃亡・次の略奪の敵に混ぜる）、`st.chaosActive`、設定の on/off、痕跡の記録。
- UI（Opus）：決着の「事故」パネル（得と損を並べる）、設定の札、殿堂の一行。
- CodeX：墓地に骨が積まれる小物、持ち逃げ犯の札（既存の種族の絵に「賞金」の帯）、モルモの台詞 12 本。

## 5. やらないこと

- 乱数だけで起きる不幸（理由が語れない）。
- 取り返しのつかない全損（金 0・名簿 0）。事故は「傾く」まで。
- 事故が事故を呼ぶ 3 段以上の連鎖。2 段で止める。
