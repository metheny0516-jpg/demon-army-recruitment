残り26技は既存の演出を維持。31技全部の実装完了ではない。
既存コマ・外部音源のSound.battleを利用。新しい姿勢絵・音源・戦闘数値は追加変更なし。
今回の吸血演出から魅了の成功を推測してハートを足すことはしない。現行の魅了通知は文字列noteで、対象ID付きの成功イベントではないため。既存ログは維持する。

## 表示契約

- 動作は eventScale / speed で圧縮。通常攻撃の動きは短くするが、既存の連鎖字幕の可読時間・950ms下限は維持。
- 全体攻撃の動作・飛び道具・命中音は一回、HPと着弾は各対象へ。死亡イベントをまたぐ既存のaoeGroupsに従う。
- skillMiss の note は空振り動作のみ。対象HP・命中線・吸収は発生しない。
- 低モーションは移動・暗転・飛び道具なし。実値は即時更新、着弾の静止表示。
- pendingHits でスキップ時もHPを確定。motion-fx は stop() で破棄。吸収対象記録も毎戦掃除。
- 描画からゲーム用乱数U.randを消費しない。core/dataの戦闘計算に変更なし。
