# 戦闘中の人物ハプニング：隔離試作

更新: 2026-09-20

## 目的

「何やってんだお前！」という損と、思いがけず助かる結果を同じ人物から生む。
現段階では面白さと読みやすさを試す。自然発生率・最終倍率は未決。

## 試験入口

- `Battle.simulate/start` の `options.forceHappenings` は試験専用。
- 4件の新規ハプニングは `testOnly: true / chance: 0`。通常の `run.js` は試験引数を渡さない。
- `battle-preview.html` の5ボタンで実戦計算を再生できる。本編セーブ・戦績は変更しない。
- 大食漢は新規事件ではなく既存処理の拡張なので、試写だけ発火判定を確定させる。

## 共通の時間契約

- 回数を数えるのは本人の通常手番だけ。追撃・反撃は回数を減らさない。
- 睡眠・接着で停止中の本人は能動的な追撃・反撃を始めない。
- 受動能力を一括停止しない。トロルの既存の肩代わり等は継続する。
- 新規4件は1人1戦1回。既存の大食漢だけは従来どおり最大2回。

## 1. スライム：くっついて離れない

- 通常攻撃を置換。本人は発動手番を停止1回目とする。
- 貼り付かれた敵は、その後の最初の通常手番を停止1回目とする。
- 双方2回。先に2回を終えた側は、接着が残っていても3回目を失わない。
- 2体とも戦場に残り、敵味方から攻撃・回復される。
- 片方の死亡で即解除。蘇生しても接着は復活しない。

## 2. トロル：戦場で昼寝

- 通常行動を置換し、1～2回休む。発動手番が1回目。
- 休んだ各手番に最大HPの10%を回復し、実回復量を `heal` で表示する。
- 防御値・被ダメージ倍率は変更しない。攻撃されても起きない。
- 受動的な肩代わり等は継続する。

## 3. ハーピー：上空偵察

- 通常行動を置換。1回休みなら離脱手番を失い、次の本人手番相当で帰還する。
- 2回休みなら離脱手番と次の手番を失い、その次に帰還する。
- 上空では攻撃・被弾・回復・全体効果の対象外。
- 帰還時の「偵察急降下」は攻撃力100%相当（通常攻撃と同じく防御を差し引く）、必中、気合0。
  `harpy_dive` の習得・選択・85%命中・気合消費とは別の事故専用攻撃。
- 地上全滅時に偵察中の本人しか残っていなければ即敗北。酒好き等の遅刻者は従来どおり到着を待つ。
- 上空で敗北した本人は `alive` のまま。空中にいたことだけで戦死・負傷にしない。

## 4. ミノタウロス：そっちじゃない

- 通常攻撃だけを置換。事故後に通常攻撃を重ねない。
- 別の敵か味方へ突進。味方なら本人も反動を受ける。
- 別対象がいなければ事故不成立として通常攻撃を続ける。
- 特性 `charge`（`src/data/traits.js`、ラウンド末の自動押し下げ）は事故ラウンドだけ抑止する。
- コマンド技 `mino_rush`（`src/data/skills.js`、攻撃・押し下げ・反動）は別ID。選択時は事故抽選を通さず、そのまま実行する。

## 5. 大食漢：半分だけだぞ

- 既存 `big_eater` の撃破後35%、最大2回、次手番休み、回復総量15%を維持する。
- HP30%以下の味方がいれば、既存の回復総量を本人と最も弱った味方へ半分ずつ割り当てる。
- 本人が満タンでも味方側の半分は回復する。余った本人分を味方へ再配分はしない。
- 対象がいなければ従来どおり本人だけ回復。
- 新しい食料消費・事件・休みを増やさない。各 `heal` に対象と実回復量を載せる。

## 自然発生へ進む条件

試写で「誰が何をしたか」「誰が何回止まったか」「損と助けの両方」が説明なしに読めることを確認してから、
戦闘単位の発生頻度、各事件の候補率、同一戦闘の上限を決める。
