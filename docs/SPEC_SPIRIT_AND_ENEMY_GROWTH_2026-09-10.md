# 仕様：気合（号令の限定）と、敵の成長の作り替え（2026-09-10）

実装担当：Claude（オーナー「そのまま進めて」）。この文書は設計の根拠と契約の記録。
前提：`docs/SPEC_ORDER_2026-09-10.md`（号令）、`HANDOFF.md` §0「次の三段」。

## 0. 一文で

**強い技ほど溜めてから出す。敵は時間では強くならず、攻めた分だけ強くなる。**
気合は人に付く（技に付けると数値管理になり、人に付けると「誰を休ませるか」という既にある判断に繋がる）。
敵の強さは征服度だけで決め、時間の圧力は警戒度＝王国の反撃で払う。慎重な人は進軍以外で徐々に強くなれる（正規統制ルートの安全弁）。

## 1. 気合（`m.spirit`）

- 軍団員ごとに 0〜3。採用時 1。
- **溜まる**：出撃して決着を迎えると +1（戦死者は除く。撤退・全滅の担がれた者も +1）。留守番で決着を1回迎えると +2。上限 3。
- **使う**：号令は気合を使う。`TRAITS[id].order.cost`。
  弱い技 1（怪力・火球・先制・悪戯）、中 2（疾風・集団戦法）、強い技 3（大火球・ぶちかまし・血の雄叫び）。
  名指しした瞬間に引く（`Game.answerOrder`）。決着で +1 が戻るので、実質は cost−1。
- **候補**：気合が cost 以上の者だけ。足りない者は提案に出ないが、モルモの一言に「◯◯は気合が抜けたまま」として添える（`order_offer.unready`）。
  号令できる者が全員足りなければ提案そのものを出さない。
- **見せる**：編成画面のカードに「気合 ●●○」。号令の候補ボタンに「（気合3）」。
- 傭兵・召喚物・テストの直作りユニット（`spirit` 未設定）は**制限なし**（`unit.spirit === null`）。sim は号令を使わないので影響なし。
- ランダム性は入れない（候補が乱数で消えると悔しさが自分に向かない）。息切れ1手番の代償はそのまま。

## 2. 敵の成長

今：敵の段階 = 魔王軍レベル（max(征服+1, ターン×0.5)）+ 作戦の offset。戦うほど時間が進み、時間で敵が強くなる。がんがん戦う人ほど急に壁に当たる。

これから：
- **通常作戦（略奪・討伐・進軍）の敵の段階 = 征服+1 + offset。** 時間では上がらない。
- **段階内の慣れ**：同じ段階で戦うたびに敵の能力 ×(1 + 0.04×n)、n は「その段階で戦った回数」（上限5＝+20%）。`st.stageFights[段階]` で数える。作戦カードに「王国はこの辺りの守りを固めつつある（+8%）」。
- **段階を上げたときの手応え**は段階表の差そのもの（+15%前後）。別の倍率は掛けない。
- **反撃（防衛戦）は今までどおり魔王軍レベル基準**（討伐隊は時間で厚くなる＝時間の圧力はここで払う）。勇者は段階8固定。
- 応募者の伸び（魔王軍レベル）と叩き上げ（レベル5以上で低ティア×1.7）は変えない。慎重に時間を使えば応募者は強くなる＝安全弁。緩みすぎたら `applicantGrowth` で締める（sim で判断）。
- 壁は二つだけ：討伐隊（警戒度で来る）と勇者。

### 2.1 sim の合格帯

置かない（構造を変える変更）。報告：全戦略のクリア率・平均戦闘数・全滅/ラン・防衛戦/ラン、前後各2回。
「略奪4回→侵攻」「慎重経営」が最強優先より**易しくなりすぎない**（差が+15pt以内）ことを見る。超えれば `familiarityPerFight` を 0.06 へ。

## 3. 契約

- `MONSTER_RULES.spirit = { start: 1, max: 3, perBattle: 1, perHomeTurn: 2 }`（monsters.js）。
- `ENEMY_GROWTH = { familiarityPerFight: 0.04, familiarityCap: 5 }`（enemies.js）。
- `TRAITS[id].order.cost`（1〜3）。
- `Battle.makeUnit`：`spirit: m.spirit ?? null`。`orderCandidates()` は `spirit === null || spirit >= cost` の者だけ。候補に `cost`, `spirit` を足す。`order_offer.unready: [{ unitId, name, skillName, spirit, cost }]`。
- run.js：`hire()` で `spirit = start`。`migrateState` で無い者に `start`。`tallyBattleRecords` の隣で出撃者 +1、`processDepartments` で留守番 +2。`answerOrder` で cost を引く。`buildMission` の段階を征服基準に、慣れの倍率を `scale` に掛け、`mission.familiarity` に載せる。`stageFights` は決着（`settleContinue` の勝敗どちらでも、`settleRetreat` も）で +1。
- UI：`monsterCard` に気合の表示。`askOrder` の note に unready を添える。作戦カードに慣れの一行。

## 5. 未決（既定）

- U1 気合の初期値 1（既定）。0 にすると1戦目は号令できない。
- U2 全滅で戦死した者の気合は消える（当然）。担がれた者は +1（既定：出撃した扱い）。
- U3 慣れをターンでも減らすか（放っておくと守りが緩む）。既定：減らさない。
