# 仕様：力試し ― 第二幕のあとに、負けても終わらない強敵戦（2026-09-18、統括 Claude Fable）

オーナー指示（2026-09-18）：「第二幕が終わったがバトルがぬるい。強敵と戦いたい。難易度高めの敵を作って。**力試し的な感じで、全滅しても終わらないように**」。
第三幕の物語は別チャットで設計中なので、**ここでは物語に触れない**。第三幕が入ったら、この札はそのまま「第三幕の前の腕試し」になる。

## 0. 一文で

**第二幕決着後の作戦会議に「力試し」の札を1枚足す。相手は今いる敵将と勇者一行を「勝つたびに強くなる」形で並べた梯子。稽古と同じで誰も死なず、全滅しても敗北の報告だけでランは続く。どこまで登ったかが魔界史に残る。**

## 1. なぜこの形か（10の問い）

- 問1・5：第二幕後は略奪と訓練だけで、勝って当然の戦いしか無い（sim：クリア率 80〜100%、平均 30 勝）。「この軍団はどこまで通用するか」を試す場が無い。
- 問2・9：相手は**この周回で討たなかった敵将**と**成長した勇者一行**。プレイヤーの選択（誰を見逃した・雇った）で顔ぶれが変わる。雇った敵将はこちら側に立つ。
- 問6：「連勝 4 で迷宮の主とアレンが並んで来た」「3段目でスライム軍団が溶けた」は話したくなる。
- 問8：札を足すだけ。新しい画面・資源・管理は無い。
- 「全滅しても終わらない」＝**訓練（`mission.training`）と同じ経路**を使う。誰も死なず、警戒度も王国攻略も動かない。全滅は `wipeCount` を増やさず、`endRun` へ行かない。
- 敗北は笑える形に：負けた回は日誌に「○○が、稽古なのに本気で泣いた」級の一行（下の 5）。

## 2. 札

`MISSION_TYPES.trial`（`src/data/missions.js`）。第二幕決着後だけ、略奪と訓練のあいだに出す（`prepareMissions` の `act2Cleared` 分岐に1枚足す。予約済み防衛の旧セーブでは出さない）。

```
icon: "🏆", title: "力試し", strategyLabel: "強敵に挑む", difficulty: "極",
strategyHint: "誰も死なない。勝てば報酬と称号、負けても失うのは面目だけ。相手は勝つたびに強くなる。",
training: true, enemyMult: 1, rewardMult: 0, payrollCoverage: 0.5, foodReward: 0, alertDelta: 0, conquestDelta: 0
```

札の本文は「段 N／相手の名／今の倍率」を出す（`王国攻略 +N` の代わりに `力試し 第N段・相手 ×1.xx`）。

## 3. 梯子（`st.trials = { level: 0, best: 0, wins: 0, losses: 0, last: null }`）

- **段 level は勝つたびに +1、負けても下がらない**（負けた段にもう一度挑める）。`best` は到達した最大段。
- 相手の倍率：`mult = 1.25 × 1.12^level`（段0 で ×1.25、段3 で ×1.76、段6 で ×2.47）。`buildMission` の `scale` に掛ける（警戒・軍圧・慣れの補正は**掛けない**。純粋な梯子にする）。
- 相手の顔ぶれは段ごとに**3つを順繰り**（`level % 3`）。素材は既存データだけ。

| 段 %3 | 名 | 隊列 | 出典 |
|---|---|---|---|
| 0 | **討ち漏らした者たち** | この周回で `slain`／`hired` でない敵将を、hp の高い順に最大5人。**2人未満なら段2の隊列を使う** | `Captains.ids()`＋`Captains.attach()`（growth は掛けない） |
| 1 | **勇者アレン一行（再々）** | 段階14 の `units`（5人）。`Captains.heroParty()` で討たなかった者が隣に立つ（既存） | `ENEMY_STAGES[13]` |
| 2 | **連合軍総力戦** | 段階13 と 12 の units を合わせ、hp の高い順に5人 | `ENEMY_STAGES[11..12]` |

- 勇者アレンの `hero_awaken` など既存 traits はそのまま（強敵らしさ）。**新しい技・traits は作らない**。
- **雇った敵将は相手側に出ない**（既存の `hired` 判定）。討った敵将も出ない。→ 「全員討った周回」は段0 が連合軍になる。それも「討ちすぎた」という結果。

## 4. 決着（既存の稽古の経路に乗せる）

- `mission.training = true` なので `softenTrainingCasualties` が走り、**誰も死なない**。全滅は「全員負傷で終わった稽古」（既存 3004 行のコメントどおり）。`wipeCount`・警戒・反撃予約・`endRun` に触れない。
- 勝ち：`st.trials.level++`、`wins++`。報酬は**金 = 段階14 の reward × (0.5 + 0.25 × level)**（段0 で 55G、段4 で 165G。訓練型の `rewardMult: 0` を無視してここだけ直接入金する）、生存者に戦功 +2、**称号**（既存 `EPITHETS`／`promotions` の仕組みで MVP に「○段の壁を越えた者」を1つ。新しい称号の器は作らず、既存に1本足す）。
- 負け：`losses++`、金も戦功も無し。日誌に敗因を一行（5）。段は据え置き。
- 記録：`st.record` と魔界史に `trials: { best, wins, losses }`。殿堂の一行「力試し 第N段まで」（`best ≥ 1` のときだけ）。

## 5. 文（統括が書く。Opus はそのまま入れる）

札の描写（`descriptions`、順繰り）：
- 「勝っても土地は増えない。負けても誰も死なない。ただ、どこまで行けるかが分かる。」
- 「モルモが審判。判定は甘くない。」
- 「相手はこちらの噂を聞いて、前より本気で来る。」

勝ちのモルモ：「第{N}段、突破デス！ 次はもっと本気で来るそうデス」
負けのモルモ（`expression: "worried"`）：「全員、無事デス。無事なだけデス。」
負けの日誌（ランダム1本）：
- 「{MVP}が、稽古なのに本気で泣いた。」
- 「{相手}は帰り際に『次はもう少し粘れ』と言い残した。」
- 「訓練場の藁束が、今日だけは同情してくれた。」

## 6. 数で見る（sim）

- `tools/sim.js` に戦略「第二幕後に力試しを続ける」を1本（第二幕決着後、力試しを 8 回続けて `best` を記録。既存の `act2Cleared` で止まる仕組みは**この戦略だけ**続行）。
- 列：`力試し best 平均／段0 勝率／段3 勝率`。
- **狙い**：フル軍団で **段0 勝率 60〜80%、段3 勝率 30% 未満**。外れたら `1.25` と `1.12` を動かす（コミットメッセージに測定を書く）。上限段は作らない（勝ち続ける軍団があれば、それが「壊れ方」）。

## 8. やらないこと

- 第三幕・物語・新しい敵将（別チャットの設計待ち）。
- 通常戦の難易度（`enemyMult`）の変更。オーナー「難易度はあとで」のまま。力試しはその測定にも使える。
- 敗北にペナルティを足す（金・施設・忠誠）。「力試し」なので失うのは面目だけ。
