# 勇者襲来 — 人物と状況が交わる縦切り設計 v0.1

作成: 2026-09-09 / CodeX
状態: **レビュー用の具体設計案。実装未着手。**
上位: [GAME_DESIGN_PRINCIPLES.md](../GAME_DESIGN_PRINCIPLES.md)
対象: 通常迎撃と人物の介入を、同じ短い局面で比較する。全体仕様・本番バランス・保存APIの確定ではない。

## 0. 最初に読む要約

魔王城へ勇者一行が迫る。プレイヤーは応募者を選び、部下を守備・城下の仕事・接客などへ置き、活動を進める。
普通の編成なら普通に迎撃する。酒造担当は客に酒を勧め、元同僚は話しかけ、商人は仕事として契約を考える。
その行動が勇者へ届くか、相手が受け入れるかによって、迎撃の内容が変わる。

**人物を採っただけで、専用の勇者イベントが予約される方式にはしない。**
共通にするのは「接触して提供する」「知人へ話しかける」「条件を提示する」などの行動。
人格から自由文の行動を無制限生成する仕組みは作らない。行動と世界のルールは作者が少数定義する。
共通判定だけで無限の事件が生まれるとは主張しない。

本案でオーナーに見てほしいのは第8節の六つの進行例。
最初に数値やデータ項目を決めてもらう必要はない。
「こんなことを任せたいか」「この肩透かしは見たいか」「嫌な奪われ方はどこか」を見る。

### 今回の境界

- 通常戦闘にCHAIN・新属性相性・コンボ・新しい操作ギミックを足さない。
- 異常による戦闘の変質は設計する。専用の例外まで全面的に汎用化しない。
- 時間、人数、資材はこの短い比較試作の仮設定。本編の一日方式や上限には昇格させない。
- 洪水・反乱・研究全体・自律剣・世界征服ENDは今回は作らない。
- 迎撃を退ければ試作終了。「勇者が転職したから人間界全土を征服」とは扱わない。
- 理論上の面白さを確認する文書であり、試遊済み・勝率検証済みではない。

## 1. 局面とプレイヤーの操作

### 1.1 初期条件

この試作は治世の途中を切り取る。城、城下の酒場、城門前の三か所だけを扱う。
移動の接続は「城内 ↔ 城門前 ↔ 城下の酒場」。隣接一辺を一区間で移動する。
古参オークのガロと門番のガンツが既に勤務しており、追加候補六名から最大三名を雇える。
登場人材は計八名。最大五名を抱える制限は比較試作を読みやすくする仮枠であり、本編20体制限の変更ではない。
応募者を全部採れる設計にはせず、通常要員と職場要員を選ぶ意味を残す。
開始時に限り在籍者と初期採用者の持ち場を自由に置く。途中採用者は城内から勤務・移動を始める。
途中採用もでき、未採用者は最後の準備区間まで待つ。無限求人・再抽選はこの試作に入れない。

通常賃金と生活費はこの短期間の支払準備済みとし、給与操作を毎区間要求しない。
希望給与は人物情報として表示するが、この試作では給与経営の面白さを検証したことにはしない。
人事交渉用に別枠の6Gを用意。契約成立時のみ支払い、通常勤務の財源と二重使用しない。
試作終了後の賃金義務は記録として示す。資金が無限という世界設定にはしない。

置く物は、酒造設備、空き樽、試作用の魔力片一個、通常の門扉。
魔力片は供給有限。聖剣は勇者が所持する一個の対象として新たに表現する必要がある。
施設建設・研究ツリー・一般装備管理画面は作らない。

### 1.2 プレイヤーが触るもの

- 履歴書を読む／採用する。採用と最初の仕事の指定は一まとまり。
- 人物を場所と仕事へ置く。既存の仕事は継続する。
- 必要なときだけ指示を変える。基本は「守備を頼む」「店を任せる」「来客を迎える」程度。
- 「活動を進める」で全員と勇者一行の時間を一緒に進める。
- 接触したら通常の編成と迎撃、または成立した交渉結果を受け取る。

全員に毎回指示する必要はない。自由文の命令解釈は使わない。
採用・比較・編成の仮操作は時間を進めない。確定前は戻せる。
変わった人材のために専用の実験ボタンを必須にしない。

### 1.3 場所と仕事

| 場所 | 仕事 | 日常の働き／接触 |
|---|---|---|
| 城内 | 留守番・資材整理 | 城内の人と物にだけ接触。外の勇者を勝手に知覚しない |
| 城下の酒場 | 酒造・販売・接客 | 生産、客への提供、会話。来客がいなければ普通に仕事をする |
| 城門前 | 警備・使節対応 | 到着した相手との接触。門の開閉・通行許可が意味を持つ |

仕事は能力を貸し出す遠隔バフではない。
ガロも接客へ置けるが、酒を製造する能力はない。酒造担当も戦えるが前衛適性は低い。
迎撃隊へ入ると職場を離れる。勤務しながら同時に別の場所で戦うことはできない。

## 2. 人物八名 — まず人物性を置く

下記は架空の固定候補。個体データの本番追加ではない。
「表示」は実際の履歴書案。「内側」は設計者用の行動根拠で、全項目を画面へ並べない。

| 人物 | 履歴書で見せること | 内側で必要な性質 | 普通の価値 |
|---|---|---|---|
| ガロ／古参オーク・在籍 | 前職：最前列。希望：新入りを死なせたくない。 | 前衛能力／仲間を守る優先／守備命令。未知の反乱癖などは付けない | 前に置いて攻撃を受ける。戦功のある古参 |
| ガンツ／石像の門番・在籍 | 門を任されて十二年。「通すなと言われた者は通しません」 | 通行を管理できる／明示された身元と指示を重視 | 丈夫な守備要員。接触の入口を管理 |
| モグ／酒造担当 | 「試作品の感想を聞かせてください。勤務時間外でも構いません」 | 酒造・提供／試飲を勧めたい／客を敵味方より客として見る | 酒の生産。戦闘では控えめな補助要員 |
| グルグ／商人 | 前職：軍需商。「揉める前に、条件を伺います」 | 条件提示・契約／利益を得たい／知った情報で交渉する | 取引と採用条件の仲介。借金情報を最初から万能に知るわけではない |
| レナ／勇者の元同僚 | 前職：アレン隊の護衛。「退職理由は、本人に聞いてください」 | 元同僚への接点／話をつけたい／信用関係を保つ | 堅実な戦闘員。交渉専門の鍵にしない |
| プル／魔力吸収スライム | 前職：魔力炉の清掃。「ひかるもの、すき」／備考：清掃後、炉が止まった | 接触した魔力源を摂食できる／魔力を欲する／有限の初期吸収容量 | 耐久役。通常の刃は食べられない |
| リゼ／普通の魔術師 | 「詠唱中だけ、前に立たないでください」 | 既存の魔術能力／依頼どおりの仕事を好む | 後方の火力。今回は秘密の研究暴走を付けない |
| ホネ吉／骸骨兵 | 前職：夜警。「皆勤です。寝ていませんので」 | 通常の戦闘能力／勤務を守る | 食事不要の堅実な兵士。特殊反応なしで成立する対照 |

「ガンツだから通さない」ではなく、通行権限と対象の身元と指示が一致したから止める。
「モグだから勇者を酔わせる」ではなく、用意した酒を接触した客へ勧める。
「レナだから和解」ではなく、特定相手との過去が会話の入口を作る。
人格を必ず悪さへ結びつけない。ガロ・リゼ・ホネ吉が普通に働くことも、設計の成功である。

### 2.1 公開／未確認／経験で知る情報

- 確認済み：職務上できること、現在位置、命令、今持っている物。
- 本人の申告：試飲を勧めたがる等の口調。全てが重大な伏線ではない。
- 未確認：レナと勇者の別れの事情、勇者が転職に応じるか。
- 経験で知る：魔力片を食べたプルの容量変化、今回の酒を飲んだ相手の状態。

存在しない裏切り確率を曖昧な文言で匂わせない。未確認情報の中身は接触時に都合よく捏造しない。
固定比較では人物と相手の状態を最初から設定する。通常試遊で揺らすなら開始時に保存する。

## 3. 標準の勇者戦 — 戦闘だけでも成立する基準

### 3.1 現行の事実と、この試作の差分

現行敵は戦士ドルフ、勇者アレン、聖女エル、賢者ミラ。
アレンには「HP50%以下で以後与ダメージ+50%」の既存覚醒がある。
通常攻撃は先頭を狙いやすく、速度順に進む。先頭狙いの分岐は60%だが、
残りのランダム選択にも先頭が含まれるので「被弾率が厳密に60%」とは説明しない。
聖女・賢者という名前だけから未実装の回復・魔法をあるものと扱わない。
現行の最終敵数値を、二名開始の試作へ無調整で使って勝てるとは主張しない。

標準戦闘は同じ四名を基準に、既存の攻撃・防御・速度・覚醒・味方既存能力で構成する。
試作の聖剣は、既存覚醒の供給源を表す物として定義する案（現行は装備由来ではない）。
聖剣なしでもアレンの通常剣術は残る。基準戦の戦術を増やすために追加必殺技を作らない。

### 3.2 準備で考えること

基本編成例：ガロ、ガンツ、レナ、リゼ、ホネ吉。
前衛二名の順序と、レナを交渉へ出すか出撃に残すかを考えられる。
少人数や職場重視も試せるが、どの五名でも同勝率にすることは狙わない。

出撃前に見せるのは敵の顔ぶれ、先頭の耐久、アレンの速度と覚醒、現在の自軍の位置。
「誰を前へ置くと何が変わるか」を読めるようにする。
編成解を強制表示したり、CHAIN成立数を総合評価として提示したりしない。
通常の三名追加で戦える道を用意し、特殊反応がないと突破不能にしない。

### 3.3 育成を実感する最小の扱い

古参ガロは既存戦功3の仮状態から始める。最初の活動区間だけ、
任意の近郊警戒で既存の小規模戦闘を一回行える（敵は勇者一行とは別の巡回兵）。
生還・功績により既存の昇進処理へ接続し、勇者戦までに変化を見られるようにする。
戦闘しない人はその区間を通常勤務に使える。二回目以降の警戒戦・無限育成は置かない。
これは本編の育成曲線を評価する代替ではなく、「自分で出した古参が育つ」一回の確認。

警戒戦もその区間の時間を消費する。勤務・給与を既存deploy経由で二重に進めない。
紙上版では戦闘結果を「勝利・生還した比較条件」等として明記し、実測扱いしない。

### 3.4 見せ方と勝敗

- 攻撃者・対象・残HP・生死を読める。通常攻撃の長尺化で解決しない。
- ガロが実際に受けた攻撃、リゼが実際に与えた攻撃等を、根拠のある短い戦果にする。
- 「ガロがいたから勝った」と反実仮想を断定しない。
- 勝利は一拍と既存の勝利演出で明確に区切る。通常勝利も特殊勝利と同格に扱う。
- 初見が苦戦し、工夫で手応えが変わるかは未測定。数値調整は将来の試作で行う。
- 敗北はこの迎撃試作の終了。「王国に敗れた」と明記し、再試行できる。
- 到着時に城門へ出せる者がゼロで、交渉等の決着もなければ無防備な占領として敗北する。編成不能で停止しない。
- 非戦闘決着をダミーのゼロ秒戦闘勝利へ偽装しない。

### 3.5 数値を決める前の確認

同じ通常編成・同じ敵で、前衛順序と育成前後を比較する。
特殊なしで勝てる、無関係な乱数だけで差が消えない、育成後に成果が見えることを確認する。
そのために必要な既存数値の調整は可能。ただし本書では勝率やクリア可能性を実証していない。
数値校正前の文書レビューでは、勝敗を比較用の仮定として読む。これを実装完了と扱わない。

## 4. 活動が進む単位 — 試作限定の短い時計

一日二決裁ではなく、三つの準備区間と一回だけの延長を試す。
現実時間の待機タイマーはない。「活動を進める」を押したときだけ進む。
出来事が起きない区間は、短い勤務報告だけで次へ進める。

| 時点 | 勇者側 | 自軍側と操作 |
|---|---|---|
| 初期 T0 | 街道上。城下へ向かうとの知らせ | 全履歴書と在籍二名を確認。採用・仕事を指定 |
| 区間1後 T1 | 城下の手前まで進む | 生産や移動が完了。任意の警戒戦はこの区間に含む |
| 区間2後 T2 | 城下の酒場前を通る／休憩する | 同所で提供・会話が可能。届いた報告を見て指示を変えられる |
| 区間3後 T3 | 城門前へ到着 | 接触・門番の処理後、敵対が続くなら編成して迎撃 |
| 延長後 T4 | 交渉の回答を待つ場合だけ滞在 | 最終回答。未解決なら戦闘か敵の撤退判断へ |

酒場へ立ち寄る理由は休憩・補給。必ず飲酒するスクリプトではない。
敵の準備はここでは移動と現場で知った情報への応答まで。毎区間の敵能力自動上昇は入れない。

### 4.1 移動・仕事・接触の順序

一人は一区間に一つの主作業を持つ。隣接地点への移動は一区間を使い、到着区間には生産しない。
その場所で起きた短い接触（話す、提供する）は、生産と同規模の主作業ではない。
ただし一人が同じ接触で何件も提供・交渉を重ねない。一区間一回の自発的な接触行動を仮上限にする。
通常の警備・通行確認は継続業務で、接触枠を消費するたび働かなくなることはない。

区間の順序：
時間切れ状態の解除 → 予約された移動・生産の完了 → 接触候補生成
→ 相手の応答を含む解決 → 事実と報告 → 敵対と到着の判定。
同じ区間で新しく製造した物は使える。生産に使った材料は、別の相手にも使えない。

T2で酒場にいた者をT3で城門へ移すと、その迎撃に参加できる。
T3でも城内に残した者を、最終編成画面だけで城門へ瞬間移動させない。
編成画面は城門に到着した人から選ぶ。場所不足の理由を明示し、閲覧の戻り操作では時間を戻さない。

### 4.2 延長と決着

面会・交渉への合意が成立すると一度だけT4まで待てる。
拒否された提案を同じ条件で繰り返して無限に時間を増やせない。
門を閉めるだけでは延長しない。既定の城門前で迎撃するため、門番一人で永遠に攻略を止められない。
T4で有効な停戦・雇用の合意がなければ、その時点の敵対意思に従って通常戦闘へ入る。

プレイヤーの採用・撤回は区間確定前なら戻せる。成立した相手との契約をUIの戻る操作で解消しない。
途中保存が必要になれば時計・所在・未決の提案・乱数結果を保存する設計が必要。本番契約は未変更。

## 5. 共通の介入モデル

### 5.1 最小情報（概念モデル。コードスキーマではない）

| 対象 | この試作で必要な情報 |
|---|---|
| 人物 | 安定したID、能力、動機一〜二個、知識、重要な関係、場所、仕事、許可範囲、状態 |
| 物 | 所在・所有者、提供／接触の可否、量、魔力や酒等の意味のある性質 |
| 状況 | 接触者、場所、時点、目的、敵対／通行／交渉の状態 |
| 行動 | 必要能力・接触・対象・資源、提案内容、応答条件、結果 |
| 事実 | いつ誰が何へ何をしたか、参照した原因、変わった状態、誰に伝わったか |

全性格パラメータ、好感度の全員相互行列、現実的な経済を作らない。
「関係」はレナとアレンの元同僚という一本でもよい。
出来事の事実と、その人物が知っている事実は分ける。商人は見ていない会話を読めない。

### 5.2 候補から行動まで

1. **可能性を絞る**：能力・接点・場所・必要物がない行動は候補にしない。
2. **命令を読む**：通常の業務を進める。明示的な禁止に反する提案は、本案の八名では原則実行しない。
   この試作は本格的な命令違反をまだ作らない。上位指針として禁止する意味ではない。
3. **本人の余計な一歩を選ぶ**：命令の範囲内で、動機に合う接触行動を選ぶ。
   「店を任せる」なら試飲を勧める余地がある。「外の者には振る舞うな」ならない。
4. **相手が応答する**：提供者の性格だけで相手の飲酒や転職を確定しない。
5. **結果を残す**：物の消費、情報の伝達、状態、契約、場所・所属の変化を更新する。
6. **次に接点ができた者が反応する**：反応が生んだ状態を使い、同じ条件への無限再反応を避ける。

候補間は「緊急の防衛 → 明示された目的 → 本人の好み」の優先を仮に使う。
好みの同順位だけを開始時seedの抽選で選ぶ。名前順、カード順、表示順を隠れた優先順位にしない。
確定した接触の再閲覧では抽選し直さない。
本案の比較進行は同順位抽選を必要としない固定条件で記述する。確率の実測値はまだない。

### 5.3 相手も目的を持つ

勇者側は討伐の目的を持つが、一枚の敵カードとして全員が同時に判断するわけではない。
限定的な相手条件を三つの比較セットで用意する（下記は固定データで、結果を見て変更しない）。

| 比較条件 | 酒への応答 | レナへの応答／雇用 |
|---|---|---|
| A：任務優先 | 勤務中は飲まない | 面会はできるが退職意思なし。交渉で必ず転職しない例 |
| B：休憩中 | 安全と思う店で酒を一杯飲む | 任務を続ける。飲酒と転職は別の判断 |
| C：離職検討 | 飲むかはA/Bと独立 | 以前から待遇に不満。知人の信用・具体条件・安全な面会があれば検討 |

Cでも「借金があるだけで転職」にはしない。受諾条件は提示内容と本人の意思で決まる。
全員の撤退意思も別に持つ。アレン加入後に残りが帰る比較条件と、戦い続ける条件を区別する。
それらの比率はこの設計で決めない。まず仕組みと体験を固定条件で比較する。

## 6. 少数の行動と、結果の具体形

### 6.1 共通行動の一覧

| 行動 | 必要条件 | 起こること | 勇者以外への再利用 |
|---|---|---|---|
| 生産する | 能力・設備・材料・勤務時間 | 一個の物を作り、在庫に残す | 酒、将来の料理等。今回作るのは酒だけ |
| 提供する | 物・接触・提供許可・本人の理由 | 相手が受け取る／断る。受領だけと消費を分ける | 使節、村人、同僚への提供 |
| 話しかける | 接触と会話を始める根拠 | 相手が応じれば情報が伝わる | 知人、取引相手、来客 |
| 条件を提示する | 交渉能力、接触または仲介、予算・権限 | 相手の条件と照合する提案が存在する | 雇用、停戦。具体契約は作者が定義 |
| 合意を履行する | 有効な受諾、資源、当事者の所在・生存 | 支払と契約・所属変化を一度だけ確定 | 通常の採用と同じ雇用の扱いへ |
| 通行を扱う | 門の担当、対象と通行指示 | 通す／止める。信書の受取と本人の入城は別 | 商人、使節、応募者 |
| 接触対象を摂食する | 対応能力・対象へ触れる機会・容量 | 対象の量・性質・所在が変わる | 魔力片、魔力源。全物質対応ではない |

「提供する」だけであらゆる贈り物の効果が自動で生まれるわけではない。
品物の性質と対象への作用はデータまたは個別ルールとして必要。
再利用できるのは接触・所有・承諾・消費の流れであり、世界知識を無制限に推論する仕組みではない。

### 6.2 酒

モグは酒場へ勤務すると一区間で試飲用の一樽を用意する（この試作中は一樽だけ）。
通常接客の許可で客へ一杯を勧める。樽全体を相手へ瞬間転送しない。
飲酒後の「酔い」は次の二区間の解決終了まで続き、戦闘では速度低下として既存数値へ反映する案。
試作用の効果候補は速度-2、最低1。強度は未測定であり本番決定ではない。
T2に飲めばT3とT4の戦闘まで有効。延長で消えると誤読させないよう残存を表示する。

小さな異常には数値表現を使ってよい。世界側に「誰が何を飲んだ」が残ることが違い。
拒否なら樽は残る。提供を断られた事実だけで反乱・報復を追加しない。
相手が飲酒を断っていても、他の客へ普通に売ったという勤務結果で終われる。

### 6.3 元同僚と雇用

レナが接客担当なら、本人の動機で知人アレンに声をかける。
相手が面会に応じると、待遇の不満等を本人が話した範囲で知識へ追加する。
グルグが同席、またはレナから次の区間に伝達を受けた場合だけ、その知識で条件を組み立てられる。

提案条件の仮例：
「一時金4G、定期給与2G、旧同行者の帰還を妨げない」。
2Gは比較条件Cの希望額として置く仮値。今の短期間は給与の期日まで進めず、次の支払義務として残す。
グルグには最初から「採用交渉は6G以内で任せる／提案まで」の選択があり、既定は提案まで。
包括的に任せてあれば個別確認なしで成立してよい。予算や旧同行者の扱いの範囲を越えるなら提案に留まる。
提案までの場合、次の準備画面に一件だけ承認待ちを出す。あらゆる事件に承認を課す設計ではない。

現場の面会は城門前でもでき、門内へ入れない指示と両立する。
転職は所属と契約の変更。攻撃力低下の代用品にしない。
受諾時点で他の勇者一行も帰還を選べば迎撃解消。そうでなければ残党との戦闘は残る。
アレン加入で枠を超えた場合は「同行・配属待ち」として保持し、無断で古参を追い出さない。
配属待ちでも敵からは外れ、将来の軍団に残る。突然弱体化して元の難易度へ戻さない。

### 6.4 吸収 — 今回の一つの明示的な異常ルール

初期プルは魔力片程度を食べられる。
魔力片を資材整理の仕事で扱い、接触・摂食すると吸収容量が増える。残った片はなくなる。
普通の魔術師が同席していなくてもこの局面では成立する。生物研究の成立過程全体は今回は扱わない。
「研究者×スライムの長期発展」まで検証したことにはしない。

強くなったプルが聖剣へ物理的に接触すると、聖剣の魔力源を食べられる。
城内に隔離したまま遠くの剣を食べない。魔法という名前だけで通常攻撃全般を消さない。

今回検討する接触は二つ。
- 城門前の面会で、持ち込んだ剣と同所のプルが接触できる状況。鞘や距離で触れないなら不成立。
- 戦闘でアレンがプルを攻撃し、命中したとき。その攻撃のダメージは通常どおり解決した後、
  生存したプルが接触した魔力源を摂食する。死んでいる個体が後から吸収しない。

聖剣は「魔力源あり」から「魔力源なし」へ一度だけ変化する。
本試作では覚醒の供給源を聖剣とするので、以後その覚醒効果を使えない。
すでに覚醒していた場合も、その供給源の効果だけが終了する。通常攻撃、本人の身体能力、他の補正は残る。
これは既存覚醒実装のままでは表せないため、後の実装では供給元の識別が必要。
CHAIN段数、報酬の予約、追加ダメージへ変換しない。

吸収後のプルには「聖剣の魔力を取り込んだ」状態が永続的に残る。
本縦切りで世界増殖まで続けないが、世界を変える状態を単発の戦闘演出として捨てない。
重大さの演出は短い中断とモルモの一言。「剣は残っています。聖剣ではなくなりました」。

### 6.5 戦闘中の自由なイベント対話は作らない

標準戦闘と吸収は計算してタイムラインへ出し、表示はその結果を再生する。
途中でユーザーが自由に雇用交渉を開始し、計算済みの未来を巻き戻す方式は本案に含めない。
交渉は戦闘前、摂食は限定した接触で解決する。
例外を許すことと、あらゆる時点にあらゆる操作を許すことを区別する。

## 7. 複数人、競合、再反応

### 7.1 小さな解決順

同じ接触では、物理的な通行・接触可否を先に確認する。
同じ区間に長距離の会話と移動を後付けしない。区間末に得た情報を別地点へ伝える指示は次区間に届く。
次に行動候補を作り、同じ物を使う候補が競合する場合は一つを確定してから残りの成立条件を再確認する。
前提がなくなった行動は不成立として記録し、別の結果へ強引に代替しない。

短い提供・会話はその接触内で応答まで完結する。
情報を受けた同席のグルグは未使用の接触枠があれば条件提示できる。
別の場所なら次区間の情報伝達と移動が必要。
新しい状態で既に行動済みの本人を何度も再発動させない。
この上限は共通人物行動の作業量を絞る試作仮定であり、CHAIN上限ではない。

契約は、当事者の返答 → 資金確保 → 所属変更を一まとまりで確定。
提示の瞬間に相手を味方にしない。提示後に敵対行為が起きたら、受諾前の条件を再確認する。

### 7.2 競合の例

- 門番が入城を拒否：城外の会話は可能。城内のグルグとの直接面会だけ不成立。
- 一樽へ二人が要求：量を先に確保。一杯ずつ足りるなら両方、足りなければ供給できない側が出る。
- 会話と攻撃：合意された面会中は守備命令が通常攻撃を開始しない。合意がなければ敵対優先。
- 転職と吸収：所属変更は摂食欲を自動で消さない。ただし味方の所有物へ触れる許可がなく、
  本案の通常指示では新たに勝手な略奪を始めない。既に摂食済みの魔力は転職後も戻らない。
- 酔った勇者との契約：酔いだけを同意とみなさない。本案では有効な契約への意思確認は必要。
  交渉は酔う前にまとまるか、酔いが軽く意思表示可能な条件で成立する。泥酔で意思不明ならT4でも不成立。
- 誰も関われない：普通の勤務を進め、そのまま迎撃する。

## 8. 六つの具体進行 — まずここを見てほしい

各例の戦闘勝敗は説明用の仮定。共通ルールを紙上で追った結果で、実測ではない。
以下は六本のイベントを実装する一覧ではなく、第5〜7節を別の状態で解決した比較例。

### A. 普通に軍を育てて勝つ

採用：レナ、リゼ、ホネ吉。全員を守備へ。勇者条件A。
T1：任意の警戒戦へガロらを出す。生還した比較ではガロが既存の小隊長へ昇進。
T2：全員が城門の守備へ移る。酒場に担当者はいない。レナも守備を優先。
T3：来訪。レナが元同僚でも、仕事と接触の仕方から自動で転職交渉は起きない。
編成でガロを先頭へ。勇者戦を普通に行う。
結果例：「ガロが前線で四度攻撃を受け、リゼが最後の攻撃を放った」。
勝ったら短い勝利と迎撃成功。隠しイベント不足の評価を付けない。
見たい感情：普通に強くなった。あいつを連れてきてよかった。

### B. 酒造担当が思いがけず役立つ

採用：モグ、リゼ、ホネ吉。モグに城下の店を任せる。勇者条件B。
T1：モグが試飲樽を作る。
T2：休憩中のアレンへ一杯を勧め、相手が飲む。魔王は酔わせろと命じていない。
報告：「モグ殿の新酒、旅の方に好評です」。身元を知らない段階で勇者と断定しない。
T3：アレンが来訪し、門番が身元を確認。既に見た飲酒客と一致する事実がつながる。
モルモ：「魔王様、勇者です。先ほどまで、うちで飲んでいた方です」。
速度が落ちた勇者と普通に戦う。そのまま勝って終わってよい。
常に別の災難を追加しない。次の試行で相手が酒を断れば通常戦闘になる。

### C. 通常の清掃が、聖剣を食う準備になる

採用：プル、リゼ、ホネ吉。プルに城内の魔力片整理を任せる。
T1：片を食べる。モルモ「片付きました。箱ごとではなく、中身だけですが」。
容量変化は人物欄へ残る。聖剣を食べる未来までは予告しない。
T2〜T3：プルを城門へ移し、迎撃へ入れる。
戦闘でプルがアレンの攻撃を受けて生存した比較では、接触から吸収が成立。
覚醒の供給源がなくなり、残りは普通に戦う。初撃で倒れた比較では吸収しない。
結果：「聖剣の魔力はプルに残った。アレンは剣術で戦い続けた」。
特定の乱数命中を引くまで待つことが最適になるなら、試作時に接触の設計を再検討する。
今回の案は世界を飲み込む最終形ではなく、一つの異常が戦闘の前提を変える最小例。

### D. 元同僚と商人が、勇者を雇う

採用：レナ、グルグ、リゼ。レナとグルグを来客対応へ。勇者条件C。
グルグへ「6G以内で採用交渉を任せる」と設定する。
T2：城下でレナが知人へ話しかけ、アレンが離職検討を話す。同席のグルグが具体条件を提示。
相手が回答を持ち越し、面会延長が成立する。
T3：城門前で旧同行者も条件を確認。受諾可能な比較では契約を履行し4G支払う。
全同行者が安全帰還を選ぶ比較では迎撃解消。
モルモ：「魔王様、勇者一行の到着です。こちらの一名は、出勤です」。
そこで試作終了でもよい。アレンの配属待ちと給与契約は残す。
人間界征服とは記録しない。残り三人が敵対を続ける比較では、その三人と戦う。

### E. 門番の堅実さで、思惑は通らない

採用：グルグ、リゼ、ホネ吉。グルグは城内。門番へ「外の者を入れるな」。
アレンから面会申し出が来ても、ガンツは入城を拒否する。信書は受け取れる。
グルグは待遇事情を知らず、入城もないので即契約できない。
T3時点で城外へ出る時間を用意していなければ通常迎撃。
モルモ：「ガンツ殿、誰一人通していません。商談相手もです」。
厳格な命令は働いた。門番の隠れた裏切りではない。無条件で資金没収もしない。
これが面倒な失敗に見えるか、人物と配置の結果に見えるかをレビューする。

### F. 二人が同じ相手へ関わるが、全部は起きない

採用：モグ、レナ、グルグ。三人を酒場へ。勇者はCかつ勤務中飲酒拒否。
T1：酒を作り、他二名も接客へ。
T2：モグが酒を勧めるが断られる。レナの会話は別の条件なので成立。
グルグは共有された情報で提案する。酒を飲まないことを理由に会話まで止めない。
T3：交渉が成立すればDの結末へ。拒否なら迎撃、必要な人を城門へ移しておく。
モルモ：「お酒は売れませんでした。雇用契約の話は、進んでいます」。
成功を増やすために「勇者が飲む」「転職する」を両方確定させない。

### 第七の脚本を足さず確認する差分

Dでグルグを遠方の仕事へ置く：レナは話せても、条件提示は間に合わない場合がある。
Bで提供を禁止：普通に酒を作って在庫が残る。陰で必ず振る舞う罰は付けない。
Cで魔力片を使わない：初期プルでは聖剣を食べる容量が足りない。
Aで警戒戦をしない：昇進は起きないが、通常攻略自体を不成立にはしない数値が必要。
Dで予算を3Gにする：4Gの条件は履行できない。資金を負数にして雇わない。
この違いが人物名別の専用分岐を増やさず出せるかを、設計の評価に使う。

## 9. 報告と履歴

基本画面は一つの軍団・活動画面と履歴書、既存戦闘画面。
複雑なマップ移動UIを作らず、人物の現在地と仕事を同じ欄で見せる。
通常勤務は一行にまとめる。特殊反応がなければ「異常なし」を毎人承認させない。

大きな変化はモルモの発話で伝え、詳細を開くと短い事実を読める。
例：モグが酒を提供 → アレンが飲む → 酔いが残ったまま到着。
内部の因果IDや行動スコアを、商品画面へ直接出さない。
酒の提供者をモルモがまだ知らないなら、その時点で断定しない。後の報告で判明してよい。

記録の概念：
原因となる事実、人物ID、対象ID、時点、前後の状態、伝わった相手。
同じ事実を、戦闘前の報告、戦闘での作用、試作の結末で参照する。
「この人を採ったから勝った」のような推測は書かない。

永続：採用、契約、所属、魔力片の消費、聖剣の状態、プルの吸収、昇進、戦死。
一時：酔い、現在の面会、移動予定、一戦のHP。
通常戦闘も、交渉成功も、同じ「勇者襲来への決着」だが、戦闘勝利数へ混ぜない。

## 10. 手書きと共通処理の境界

| 共通にする部分 | 手書き・個別定義が必要な部分 |
|---|---|
| 接点、場所、能力、知識、許可の確認 | 人物の口調、経歴、好み |
| 物の提供、相手の受領・拒否、消費 | 酒の性質と酔いの効果 |
| 会話での情報伝達と提案 | レナとアレンの関係、相手の受諾条件 |
| 契約の履行と所属変更 | 採用契約で何を約束できるか |
| 接触と容量と物の状態更新 | 聖剣が何を供給し、失うと何が変わるか |
| 原因と結果の記録 | モルモの短い肩透かし、剣を食べた瞬間の見せ方 |

物を消費する共通処理だけで「聖剣を食べる」が安価に完成するとは考えない。
ここが本案で最も新しい実装負担になる。
自律剣や世界増殖へすぐ伸ばさず、同じ提供が村人・使節にも通る程度の再利用を先に確認する。

## 11. 現行からの再利用と改修が必要なところ

| 現行 | 判定 |
|---|---|
| 履歴書カード、安定した人物ID、名簿 | 再利用候補。場所・仕事・知識を新たに扱う必要 |
| 既存の攻撃、防御、速度、編成、昇進 | 標準戦闘の土台。試作の人数と成長に合う数値校正が必要 |
| 敵四人とアレンの覚醒 | 通常敵の土台。聖女の回復等を既存機能と誤認しない |
| 戦闘計算と演出の分離 | 維持。例外後の事実をタイムラインで見せる |
| buildChanges、spotlight、memory | 考え方と事実表示を参考にする。会話や契約をそのまま格納できる契約ではない |
| debtsの遅延保存 | 予約の参考。ただし人物の欲望や対象の応答を遅延数値伝票で代用しない |
| maybeEventの条件付き一件抽選 | この共通介入の本体にはしない。複数の行動・応答を表せない |
| 勝利後の勤務・給与・進行 | 世界区間と切り分けが必要。二重決済に注意 |
| 現行CHAIN、既存シナジー | 今回追加しない。普通の能力があることは許すが、人物介入の条件や成功尺度にしない |
| 聖剣の物体・覚醒の供給元 | 現行に独立管理なし。新しい限定的な状態と例外処理が必要 |
| 非戦闘解決、配属待ちの加入者 | 現行勝利フェーズに偽装せず新しい接続が必要 |

本番run.jsとbattle.jsを同時に書き替える計画は立てない。実装担当・順序・契約はレビュー後に分ける。
最初の実装候補は独立した比較用入口。現行本編セーブや魔界史へ直接混ぜない案を推奨するが未決。
画像、音声の追加制作はこの設計では要求しない。

## 12. 境界と失敗の確認表

将来の実装で確認したい性質。今回テストコードを書いたという意味ではない。

| 条件 | 期待する結果 |
|---|---|
| 特殊人材なし | 通常勤務と標準戦闘で完結 |
| 関係はあるが本人不在 | 遠隔会話や転職を発生させない |
| 商人が秘密を知らない | その秘密を使う提案は候補にならない |
| 酒はあるが相手が拒否 | 未消費。酔いなし |

| 知識が伝達された | 同席または次区間の伝達後に限り、その情報を使える |
| 提案予算不足 | 履行しない。負残高・敵の無断加入なし |

## 13. Red Teamと修正の判断

1. **普通の編成がただの最強五人選びになる。**
   数値を確かめず「普通も楽しい」とは言えない。前衛順・育成前後・職場との人員配分で比較する。
   それでも単調なら、まず既存の働きとテンポを修正。新コンボを足して解決しない。

2. **特殊三名を採ると毎回転職へ最短到達する。**
   相手の離職意思を全回固定しない。ただし最後の低確率ガチャで妨害もしない。
   特殊決着へ恒久的な上位報酬を付けない。固定比較と自然な出現頻度を別に評価する。

3. **三か所の移動が、ただの手順になる。**
   本案の最大の作業化リスク。所在地が物語に効かず移動忘れの罰だけなら、
   後の改稿では「持ち場と担当の接触範囲」で表し、移動操作を縮める。
   現場不在を表現したいからといって移動ゲームを守らない。

4. **接触枠と解決順が、見えない正解順になる。**
   目的の優先と行動不能の理由を報告し、カードの並び替えで発火順を攻略する仕様にしない。
   一区間一回の仮上限が自然な会話まで止めるなら見直す。

5. **スライムがただの覚醒解除役になる。**
   ここは未解決の懸念。聖剣とプルの状態が戦後に残り、所属・雇用と同じ世界状態として扱えることを条件にする。
   台詞を増やすだけで物の変化がなければ、戦闘補正への回収と判定する。

6. **勇者の転職を見た直後に終わって惜しい。**
   今回は短い縦切りなので終了するが、本編なら継続価値が大きい。
   試遊で「もうこの人で戦いたい」が出れば、それは次の設計材料。即ENDが最善と一般化しない。

7. **安全すぎる。**
   今回は命令違反の全体系を入れない。予期せぬ提供・相手の拒否・剣の摂食でまず検証する。
   この範囲から世界災害や古参の独断死まで面白いと結論しない。

8. **作者が選んだ気の利いた固定例だけで満足する。**
   第8節の例に加え、場所・情報・相手応答を一つずつ変える。
   専用イベントを足さずに結果が変わるか、変わらない場合も理解できるかを見る。

## 14. レビュー・試作への進め方

### 今回ここまで

文書の縦切り設計と、矛盾・境界の紙上点検。ゲームコード・数値・API変更なし。
時間三段階、接触上限、比較用資金、酔いの数値、候補八名はすべてv0.1の仮設定。

### オーナーに見てほしいこと

第8節を読んで、特に次の三点を自由に答えてもらう。全項目の承認作業にはしない。

- 一番見たい展開と、退屈または嫌に感じる展開はどれか。
- 部下へ仕事を任せた感覚があるか。それとも正しい位置へ鍵を置くパズルに見えるか。
- 勇者転職で短く終わること、聖剣を食べて戦いが変わることにワクワクするか。

### レビュー後の候補順

1. 紙上の流れで、特に移動と接触の手間を修正する。
2. 小さな独立試作の範囲と保存・計算契約を決める。
3. 通常迎撃と「提供→相手の応答」を実装候補の最小単位にする。
4. 同じ基盤へ会話・契約、次に聖剣吸収という明示的な例外を接続する。
5. 普通・軽い異常・大きい変化・非戦闘決着を比較する。
6. 横展開の判断。洪水や全研究システムはその後。

この順序は通常戦闘を完成させるまで異常を待たせる意味ではない。
最初の小さな実装から通常と異常を並べる。実装着手はまだこの文書の成果に含めない。

### 上位指針の十ゲートとの対応

1〜3：通常の働き、人物の動機、意図しない接触で確認。
4・9：同じ行動を別の相手・場所へ適用し、物・所属の変化を残す。
5〜7：人物への興味、報告と事実、次に違う配置を見たいかを試遊で確認。
8：移動と接触枠、報告量を主なリスクとして監査。
10：CHAIN拡張も、全人物専用イベント表も作らず、共通行動と限定した手書きを分ける。
全ゲートを満たしたと実証したわけではない。特に通常戦闘の楽しさと操作負担は未検証。
