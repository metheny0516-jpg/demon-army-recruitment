## 原稿から、現行実装に合わせた調整

1. 鉱山は既存地図ではコボルト領。コボルトとオークが一緒に働く場所として描く。種族・地図データを書き換えていない。
2. 神殿の戦闘隊列にはアレンはいない。アレンと対面→避難民の退避を待つ→アレンとエルが護衛して去る→残る守備隊と戦う。アレンを倒したとは言わない。原稿の「勇者との初戦」は未実装で、勇者決戦は王都／防衛の既存戦闘に残る。
3. 王都の砦の実戦闘の敵将はガレス。グラハムは遠征の布告の人物としてのみ出す。ガレスをグラハムと呼び替えたり、討った敵将を復活させたりしない。
4. 地形上、町h10は砦h11より先に制圧する。第7章は砦からの帰還報告として、既に持つ町で発生させる。二度目の制圧戦を増やしていない。
5. 第7章は住民の話を聞く正規側の場面。食わせる／搾るの選択と資源処理は未実装。台詞で食料を無料生成・没収しない。
6. 負傷者の治療、旗、門衛のやり取り等は場面描写。特定の自軍キャラの生存を必須にせず、実名の捏造や特定種族の強制はない。
7. 贈って鉱山を得た場合や旧セーブで既に領有していた場所は、武力解放したとの報告を作らず、次の目的へ進む。

## 実装で見つけた既存不具合の修正

`Game.applyMissionOutcome` が `territoryMode === "take"` だけで領土化しており、土地の**前哨戦の勝利で領土を取れていた**。
`missionPhase !== "outpost"` を追加した。前哨では敵情と本戦への進行のみ、本戦勝利で領土を得る。
これはStory無効時にも適用する、実際の進行の修正。既存の「前哨では征服しない」というカード表示・契約に合わせた。
報酬や入金回数は変更していない。戦数・警戒・給与回数への影響は試遊で確認すること。

## 保存・進行契約の追加

- `st.story.route = { version:1, completed:{}, pending:[], shown:[] }`。勇者撃退後は `defenseDecision` が `pending` → `continue` / `advance`。
- `completed[id] = { turn, place, visit? }` は達成履歴。pendingは決着時に確定した表示場面の写し、shownはキューに積んだ場面ID。
- `mission.storyRoute` は対象作戦の識別子。既存 `mission.story === "goblin_rescue"` と分離。
- 達成は実際の勝利決着後、領土取得を確認して一度だけ。前哨、訓練、略奪、撤退は達成しない。
- 決着報告は再描画や再読込で作り直さない。既存story.queue/nextを通って事件・採用へ戻す。
- 物語の記録は既存の痕跡kind `story`、タグ `route_completed`。新しいkindは増やしていない。
- 旧セーブにrouteがなければ初期化。未読の旧征服度連動の第2章以降の場面を除去し、現在の事実に合う目標を出す。既読の結末は再表示しない。
- Story無効時と地図なしの既存試験は旧進行。無効時には目標や追加作戦を出さない。
- 章を飛ばして王都へ到達した場合はその成果で着地し、通っていない章をまとめて再生しない。
- 勇者撃退後は `Game.storyChoose` で明示的に方針を決める。選択待ちは保存対象。`storyDone` では飛ばせず二重選択も無効。続行時は既存 `heroCame` を維持し同じ幕で再襲来させない。第二幕へ進む選択時だけ `beginAct` を実行する。Story無効の幕替わりは従来どおり。

## Opusにお願いする検証

1. 最新本線とこの枝の基点・差分を確認し、別の統合枝へ取り込む。本線で直接検証しない。他の作業枝や未承認ハプニングは混ぜない。
2. `node tools/test-story-route.js` と既存Node全件を確認。Git履歴比較を行うテスト用の基点コミットも取得する。テストの期待値を緩めて通さない。
3. `sh tools/browser-tests/run-all.sh` を実行。ただし既存の大半は `?nostory=1` なので、それだけで物語の本番経路を検証済みにしない。
4. **Story有効・新規開始**で、第1章の即位・面接・救援・地図から進む。目標と隣接する札を選び、鉱山→関所→神殿→報復隊→砦→町→王都→第二幕を確認。会話を自動で消したケースだけで合格にしない。
5. 390×844、必要なら360px幅で、顔・話者・台詞・背景・送りボタン・目標カードを目視。横はみ出し、文字切れ、重なり、二重タップ、戻る操作を確認。通常速度と早送り、戦闘スキップでも次の場面へ進めること。
6. 関所・神殿・砦の**前哨勝利では領土化せず、本戦の札が出る**こと。本戦勝利で一度だけ領土と決着場面が出ること。
7. 鉱山の敵は一般兵が人間の姿。既存の不意打ち敵将が混ざる場合はその固有の姿を保持。神殿ではアレンと対面するが、戦闘で倒したことにはしていない。
8. 作戦会議・編成・前哨勝利後・決着画面・物語の途中で保存/再読込。進行不能、既読反復、報酬再加算、同じ物語の二重記録がないこと。
9. 救援失敗、鉱山への贈り物、関所の略奪、物語対象での撤退/敗北、通常鎮圧、防衛割り込み、神殿を迂回して王都へ向かう場合を確認。未達成の戦果を台詞にしないこと。
10. **王都未攻略・低い征服度で勇者を撃退する経路**で二つの方針を確認。続行なら第一幕に残り王都へ進める。勝利宣言なら魔王城の結末→第二幕。王都陥落・国王捕縛を捏造しない。選択ボタン、二重タップ、選択待ちでの再読込も確認。
11. 旧セーブで未読のch2_open/finaleが残る場合と、既読finaleの場合を確認。過去の章を再生せず、正しい場所へ戻ること。
12. 数値を強化しない通常の軍団でも試遊し、前哨修正で戦数が増えた影響、警戒・給与・立て直しを確認。通常のプレイで正規筋を追えるか、勇者の早期襲来で毎回終わってしまわないかを報告。難易度調整が必要なら原因と最小修正を明記する。
