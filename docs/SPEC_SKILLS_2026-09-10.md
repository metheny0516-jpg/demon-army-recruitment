## 0. 一文で

**出撃を重ねた者は、種族ごとの上位技を覚え、基礎能力が少し伸びる。** 種族の固有特性（怪力・火球・先制…）が技の1段目。出撃6戦で上位技に**置き換わる**。上位技は毎回ではなく**条件付きで発動**し、通常攻撃の出番を残す。

オーナー決定（2026-09-10）：解放条件は**出撃数だけ**（留守番では育たない）。上位技は**置き換え**（まず置き換えで試し、バランスを見る）。技は**種族ごと**に作る（共通特性を重ねてもよいが、種族の技が主役）。

## 1. 目的と、やらないこと

目的：
- 「だんだん強くなる実感」（オーナー）。古参が新人と違う存在になり、死ぬと惜しくなる。継承（遺物・縁の者）はこれがあって初めて効く。
- 種族を育てる楽しみ。「オーガを6戦使うとぶちかましを覚える」が採用の判断に乗る。

やらないこと：
- レベルの表示。経験値は裏で持たない（出撃数がそのまま経験）。
- 3段目以降の技、技の選択（分岐）、技の忘却・付け替え。
- 経験の中身で付く共通特性（頑丈・しぶとい・担がれ慣れ・城の主）。次の仕様。
- 王国の反撃、全滅後の再建。
- 敵側の技。敵は今のまま。
- 技の専用演出（カットイン等）。発動は既存の `trait_trigger` の描画で出す。名前が出れば足りる。

## 2. 種族技

### 2.1 形

技は**特性**として実装する（`TRAITS` の項目）。battle.js は特性のフック（`modDealt / modTaken / postAttack / onTriggeredEvents / onRoundEnd / onLethal / lateArrival`）を既に読むので、新しい戦闘の仕組みは作らない。技である印として `skill: { species, tier, replaces }` を持つ。

```js
  ogre_charge: {
    name: "ぶちかまし",
    desc: "敵が3体以上いるとき、攻撃が敵全体に及ぶ（本人も反動で少し傷つく）",
    skill: { species: "ogre", tier: 2, replaces: "brute" },
    lines: { unlock: ["……体が、覚えた", "次は全部まとめてだ"], use: ["どけぇッ！", "まとめて潰す"] },
    postAttack(ctx) { /* ... */ }
  },
```

- `tier: 1` の技＝種族の既存固有特性（`fixedTrait(s)`）。**新設しない**。`replaces` で1段目を指す。
- 上位技に置き換わると `m.traits` から `replaces` の特性が消え、上位技の id が入る。**遺物・共通特性・癖はそのまま**（`fixedTrait` だけが対象）。
- `lines.unlock` は覚えた瞬間の本人の一言（結果画面）。`lines.use` は発動時の一言（戦闘のキャプション）。各3本以上。人物ごとの脚本は書かない。

### 2.2 解放

- 条件：`m.record.battles >= SKILL_RULES.unlockBattles`（既定 **6**。data に置く）。撤退した戦いも1戦に数える（出撃はした）。負傷中は出撃できないので伸びない。
- 判定は**決着処理の中**（`settleContinue` と `settleRetreat` の両方。継承のカウンタ更新と同じ場所）。条件を満たしたら置き換え、`notes` に「{name}が【{技名}】を覚えた」、結果画面で本人の `lines.unlock` を一言。
- 縁の応募者・遺物持ち・傭兵：傭兵（`mercenary`）は育たない。それ以外は同じ規則。
- 上位技を持つ者が離脱して遺物を残す場合、遺物の中身は**癖の特性**から選ぶ（既存の規則：`fixedTrait` 由来は除く）。上位技は遺物にならない（種族技は本人のもの）。

### 2.3 通常攻撃の出番を残す（オーナーの懸念への答え）

上位技は**毎回発動しない**。各技に発動条件を持たせ、満たさないラウンドは通常攻撃（1段目の効果も無し）。だから「置き換え」でも通常攻撃は残る。条件は技ごとに 2.4 の表に書く。**確率ではなく状況**で決める（敵の数・ラウンド・HP・味方の状態）。確率は「たまたま」に見えて育成の実感にならない。

### 2.4 11種族の技（たたき台。名前・数値は Terra が台詞と一緒に詰めてよい。**発動条件の種類と効果の形は変えない**）

| 種族 | 1段目（既存） | 上位技 | 発動条件 | 効果 | 要るフック |
|---|---|---|---|---|---|
| オーガ | 怪力 | ぶちかまし | 敵が3体以上立っている | 攻撃が敵全体に本来の70%。本人は与えた合計の10%を反動で受ける | `postAttack`（火球の全体化と同じ書き方） |
| 魔法使い | 火球 | 大火球 | 奇数ラウンド | 別の敵全員に70%（火球は1体50%）。当たった敵に「燃焼」：次ラウンド開始時に最大HPの8% | `postAttack` ＋ `onRoundEnd`（燃焼は敵側の flag） |
| オーク | 怪力 | 血の雄叫び | 自分の攻撃で敵を倒した | その直後にもう一撃（1ラウンド1回） | `postAttack` → `extraAction`（強欲の追加行動と同じ経路） |
| ゴブリン | 追い剥ぎ | 集団戦法 | 出撃中のゴブリンが3体以上 | 自分の攻撃が「ゴブリン数−2」回追加で当たる（各50%） | `postAttack` |

| スライム | 粘体 | 分裂 | 致死ダメージを受けた（1戦闘1回） | 倒れる代わりに HP40%の自分と、HP40%の分身（召喚物）に割れる | `onLethal` ＋ 召喚（墓地の骸骨召喚と同じ経路） |

| ゾンビ | 執念 | 腐敗 | 自分の攻撃が当たった | 相手の攻撃力を2下げる（悪戯は1）。倒れて戻ったあとは3 | `postAttack` |

### 2.5 表示

- 札の特性一覧で、技は「🗡」を頭に付ける。1段目（既存固有特性）にも付ける（技であることを最初から見せる）。
- 面接の応募者の札に「6戦で【{上位技}】」を小さく出す（採用の判断材料。数値は出さない）。
- 発動時は既存の `trait_trigger` のキャプションと `lines.use`。

## 3. 小成長

- 決着のたび（撤退含む）、出撃した者の `hp / atk / def` が伸びる。`spd` は伸びない。
- 伸び幅：**基礎値の 2.5%／戦、12戦で頭打ち**（合計 +30%）。data に置く（`SKILL_RULES.growthPerBattle = 0.025`, `growthCapBattles = 12`）。
- 基礎値は採用時の値を `m.base = { hp, atk, def }` に写して持つ（昇進の boost は base に**含めない**。旧セーブは現在値を base にする）。伸びは `base × growthPerBattle × min(battles, cap)` を**現在値に足すのではなく、毎回 base から計算し直す**（二重加算を防ぐ。昇進の boost は別に加える）。
- 札には「戦歴 10戦7勝」と伸びた後の値だけ。伸び幅の数字（+3）は出さない。
- 目安：10戦のガロ（攻撃11）→ 攻撃 14〜15。魔王軍レベル2段ぶん。新人は追いつくが、ガロには技と昇進と戦歴がある。

## 4. 契約（追加されるもの）

- `TRAITS.*.skill = { species, tier, replaces }`、`TRAITS.*.lines.unlock / use`。
- `SKILL_RULES = { unlockBattles: 6, growthPerBattle: 0.025, growthCapBattles: 12 }`（`src/data/skills.js` 新規。`index.html` とテストの読み込み順は `traits.js` の後）。
- 名簿の各員：`m.base`（3）、`m.skillTier`（1 か 2。表示と旧セーブ判定用）。
- battle.js：新規フック `onAllyHit(ctx)`（`ctx = { unit(肩代わり候補), ally(被弾者), attacker, dmg, log }`、数値を返せば肩代わり。1ラウンド1回は特性側で管理）。敵配列の並び替え（火遊び）と「先頭固定」（疾風）の印。契約は HANDOFF §2 に書く。
- run.js：`Game.applyGrowth(monster)`（base から現在値を組み直す。昇進の boost と合成）、`Game.checkSkillUnlock(monster, notes)`。決着処理の中だけから呼ぶ。
- 戦果の1文・KPI・魔界史は `traits` の id を読むので、上位技の id も既存の表示に落ちること（`TRAITS[id].name` が引ければよい）。

## 5. 受け入れ条件

### 5.1 sim（3条件を別々に）

`node tools/sim.js 50` を各3回：実装前／技だけ（小成長オフ）／小成長だけ（技オフ）／両方。オン・オフは `SKILL_RULES` の値で切る（`unlockBattles: 999` で技オフ、`growthPerBattle: 0` で小成長オフ）。
目標：両方オンで平均クリア率が実装前から **±8pt 以内**。超えたら `growthPerBattle` → `unlockBattles` の順に緩める。**技の発動回数**（`trait_trigger` の traitId 別）を sim に集計させ、一度も発動しない技があれば条件が厳しすぎる（未決へ）。

### 5.2 `tools/test-skills-battle.js`（コミットB）

`tools/test-tinkerer.js` のハーネスを写す。11技それぞれに1ケース以上：条件を満たす戦闘で発動し、満たさない戦闘で発動しない。
- ぶちかまし：敵3体で全員に当たり本人が減る／敵2体で通常攻撃。
- 大火球：ラウンド1で別の敵全員、ラウンド2は火球なし、燃焼が次ラウンド開始で減る。
- 血の雄叫び：倒した直後の追加攻撃が1ラウンド1回。
- 集団戦法：ゴブリン3体で追加1回、4体で2回、2体でなし。
- 疾風：ラウンド1で速度が最低でも先頭。

## 7. 落とし穴（既に踏んだもの）

- **`alive` と `onField`**：行動する側・立っている側は `onField`。技の発動条件「敵が3体以上」も `onField` で数える。
- **`skip()` は `render()` を通らない**：技の演出を `render()` だけに足すと早送りで状態が残る。
- **決着処理は `settleContinue` / `settleRetreat` の二つ**：解放と小成長はこの両方に入れる。`deploy()` の途中に書かない。
- **`newRun()` と `migrateState()` のデフォルトは別物**（継承で判明）。`base` と `skillTier` は両方に足す。
- **乱数の消費順**：技を持たない編成では `U.rand` を新たに呼ばない。持つ編成で数字が動くのは想定内だが、動いた理由を sim の3条件で分ける。
- **`departmentRoster("combat")` は今出撃している者**。育つのは出撃した者だけなので、決着処理では `contribution` の uid で回す。
- **KPI・戦果の1文は `traits` の id を読む**：上位技の id が `TRAITS` に無いと落ちる。A で先に項目を作る理由。
- **`traits.js` を Terra と CodeX が同時に触らない**（6節の順序）。
