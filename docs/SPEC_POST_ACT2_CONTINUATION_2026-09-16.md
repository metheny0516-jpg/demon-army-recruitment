# 第二幕決着後の継続仕様（2026-09-16）

## 目的

第二幕に決着してもランを終了せず、その軍団・成長・資源・城下町・領土を保存したまま、第三幕の追加を待てるようにする。
第三幕そのもの、継承、最終戦の再起、経済数値の変更はこの段階では扱わない。

## 状態契約

- `st.act2Cleared` が正本。未決着は `null`、決着済みは `{ by: "defense" | "conquest", turn }`。
- 勇者の再撃退または征服度14への到達で一度だけ設定する。
- 決着時は `phase = "result"` とし、`endRun(true)`、魔界史追加、現在スロット削除を行わない。
- `lastBattle.act2Clear` はその決着の報告だけに使う表示用の値。進行判定には使わない。
- 旧版ですでに `phase = "clear"` となった終了データは継続状態へ変換しない。

## 決着後の遊び

- 通常時の作戦札は「周辺地の略奪」「訓練」の2枚。
- 第二幕の侵攻・征服判定・勇者再来を止める。
- 第三幕への入口はまだ表示しない。画面には「第三幕は今後追加予定」と明記する。
- 王国との戦争は第二幕で決着済みなので、新しい討伐隊も予約しない。決着時に既存予約を消す。
- 採用、編成、城下町、事件、給与、食料、負傷、成長など既存の通常処理は続く。
- 周辺地の略奪には通常どおり戦死、敗北、再建、再起、最終終了の危険がある。第二幕決着後の軍団を無敵にはしない。訓練も既存の負傷・給与・食料などの仕様に従う。

## 測定

従来比較用の `tools/sim.js` は `st.act2Cleared` で止める。ゲーム内の終了記録は作らず、測定器の中だけで同等の集計用要約を組み立てる。`econ-trace.js` と `audit-elements.js` も同じ節目で停止する。

## 最低限の確認

- 勇者撃退と征服14の両方で、結果画面へ進みセーブが残る。
- 決着処理・報告・痕跡が一度だけ。
- 略奪と訓練を続けても決着印と征服度が変わらない。
- 保存・読込後も名簿・資源・決着状態を保持し、継続用の2札へ戻る。
- 旧版で終了済みの `clear` は継続状態へ復活させない。

## 変更ファイル

- `src/core/run.js`：決着状態、継続札、再決着と反撃の停止。
- `src/main.js`、`src/ui/ui.js`：一度だけの決着報告と作戦会議の案内。
- `tools/sim.js`、`tools/econ-trace.js`、`tools/audit-elements.js`：第二幕節目で停止。
- `tools/test-act-progress.js`：保存、再読込、継続戦、二重決着の対象確認。
- `tools/browser-tests/clear.js`、`tools/browser-tests/autoplay.js`：旧「第二幕＝ラン終了」前提の更新。

## 外部 Opus のブラウザ確認（390px）

全件回帰の代わりに、第二幕防衛勝利から次だけを一続きで確認する。

1. 勝利後に第二幕決着の報告が出て、終了画面にならない。
2. 「次へ」から面接を通り、作戦会議に「周辺地の略奪」「訓練」の2札が出る。
3. 略奪または訓練を1回進め、第二幕決着報告と報酬が重複しない。
4. 390px幅で再読込し、同じ名簿・資源・決着状態と2札へ戻れる。
5. ページエラーがなく、魔界史が増えていない。

## 後続

第三幕の開始時に、明示的な出陣操作から第三幕状態へ接続する。敵段階、支援拠点、巨大兵器、再起アイテム、中断復帰は別仕様とする。
