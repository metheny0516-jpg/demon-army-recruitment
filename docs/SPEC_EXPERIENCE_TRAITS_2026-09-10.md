# 仕様：経験の中身で付く共通特性（データと既存フックのみ）（2026-09-10）

実装担当者向け（Terra）。この文書と `HANDOFF.md` §0・§2 だけで始められる。
迷ったら末尾「未決」を見て、無ければ**いちばん小さい選択**をしてコミットメッセージに書く。

## 0. 一文で

**何を経験したかで育ち方が変わる。** 出撃で「倒れずに戦い抜いた」「何度も倒れて戻った」「担がれて帰った」「城を守り続けた」者に、種族を問わない共通特性が一つ付く。この仕様では**特性の定義（効果・台詞・付与条件の宣言）だけ**を作り、付与の実行（run.js）は次の仕様で行う。

## 進め方（オーナー指示 2026-09-10・全仕様共通）

- 速度優先。軽いモデルのサブエージェントを2〜10体並列（調査・ファイル単位の編集・テスト・台詞）。担当ファイルを重ねない。統合とコミットは親。
- 重い処理は直列。sim・browser-tests は**この仕様では不要**（付与されないので挙動は変わらない）。node テストだけ全部通す。
- 別セッション（CodeX）が `run.js` / `ui.js` / `battle_scene.js` / `styles.css` を編集中。**それらに触らない。**

## 2. 背景

設計会話 2026-09-10（育成）：「攻撃を受けまくった→頑丈になる」「瀕死から何度も生還→しぶとさ」「撤退を何度も経験→担がれ慣れ」「ずっと留守番→城の仕事が得意」。
種族技（`SPEC_SKILLS`）が「種族ごとの成長」、これが「経験ごとの成長」。両方重なってよい。
継承で名簿の各員に `m.record = { battles, wins, downed, carried, late, ate }` が付いた。付与条件はこのカウンタで**宣言**する（判定は run.js が後で読む）。

## 3. 定義（4つ）

各項目に `earned: { counter, at, unless }` を持たせる。`counter` は `m.record` のキー（`homeStays` だけは**まだ無い**カウンタ。run.js 側の仕様で足す）。`at` は閾値（以上）。`unless` は「このカウンタが 0 でなければ付かない」の任意指定。`lines.earned` は付いた瞬間の本人の一言（3本以上）。

| id | 名前 | 条件（宣言） | 効果 | フック |
|---|---|---|---|---|
| `hardy` | 頑丈 | `battles >= 8` かつ `unless: "downed"`（一度も倒れていない） | 受けるダメージ −15% | `modTaken` |
| `die_hard` | しぶとい | `downed >= 2` | 1戦闘1回、致死ダメージを HP1 で耐える（白骨と同じ形。白骨と両方持てば別々に1回ずつ） | `onLethal` |
| `carried_before` | 担がれ慣れ | `carried >= 1` | 撤退で担がれても**負傷しない**（データの印 `injuryFree: true`。判定は run.js が後で読む） | 無し |
| `castle_keeper` | 城の主 | `homeStays >= 5`（留守番として決着を5回迎えた） | 留守番のとき食料の調達 +1（データの印 `homeFood: 1`。`Aptitude` が後で読む）。出撃時は何もしない | 無し |

条件の数値は `earned` の中に置く（data 以外に散らさない）。**`traitPool` には入れない。応募者にも付かない。** 付くのは経験からだけ。

## 4. 書き方（守ること）

- 効果は既存のフックだけで書く。`modTaken(ctx)` は `ctx.dmg` を読んで数値を返す。`onLethal(ctx)` は `true` を返せば HP1 で耐える（`bone` の実装を写す。1戦闘1回は `ctx.unit.flags` で管理）。新しいフックは作らない。
- 台詞は全角28文字以内、数値を言わない、人物ごとの脚本にしない（`SPEC_TRAIT_LINES` と同じ縛り）。
- `desc` は「何が起きるか」を書く。「受けるダメージ−15%」は desc に書いてよい（技・成長は数値の見返しでよい。癖とは違う）。
- `relic` の名詞を各項目に付ける（継承で遺物になれるように。頑丈「胸当て」、しぶとい「お守り」、担がれ慣れ「担架の布」、城の主「鍵束」）。

## 5. テスト：`tools/test-experience-traits.js`

ハーネスは `tools/test-tinkerer.js`（battle.js を含む vm）を写す。
- `hardy` を持つ者の被ダメが持たない者の 85%（`Battle.simulate` で同じ攻撃を受けさせて比較。`U.rand` 固定）。
- `die_hard` が致死を1回だけ HP1 で耐え、2回目で倒れる。`bone` と両方持つと計2回耐える。
- 4つとも `earned.counter` が `["battles","downed","carried","homeStays"]` のいずれか、`earned.at` が正の整数、`lines.earned` が3本以上・28文字以内・数字なし、`relic` あり。
- `monsters.js` の `traitPool` / `fixedTrait(s)` にこの4つが**含まれない**。
- 既存テスト全通過（`tools/test-*.js`）。
