# 設計：全体マップと城下町の見た目（2026-09-13、Claude 起草。CodeX の設計が止まったため）

チケット `docs/TICKET_WORLD_MAP_DESIGN_2026-09-12.md` に答える文書。**設計だけ**。絵と実装はこれをオーナーが見てから。
判断は「今どこまで取ったか」「次はどこか」「金はどこから来るか」が**一目で分かる**こと。派手さは二の次。

## 0. 一文で

**城メニューの「城下町」札を開くと、魔王城から王都まで一本の道が縦に伸びる地図が出る。取った土地は魔王軍の色に染まり、城下町に建てた施設は絵が変わる。**

## 1. 立体風か 2D か → **2D（SFC 風の見下ろし）を推す**

| | 2D 見下ろし | 軽い立体風 |
|---|---|---|
| スマホ縦 390px での字の読みやすさ | 地点を縦に並べられるので大きく置ける | 奥行きで遠い地点が小さくなり読めない |
| 状態の色替え（灰→染まる→煙） | 平面の塗り替えで済む | 陰影と合わせる手間が地点ごとに要る |
| 絵の枚数 | 背景1＋小物 | 背景1＋角度ごとの差分 |
| 既存の画風（太いインク・くすんだマット）との相性 | ベスティアリの地図の見開きに見える | 3D 風は画風が浮く |

試作画像は CodeX が作れなかったので**未比較**。上の表は画面の都合だけで判断している。2D で1枚試作してから決めてよい。

## 2. 地図の構成（スマホは縦スクロール1本。横スクロールなし）

```
 上 ┌──────────────────────┐
    │  第二幕：隣国（霧の中、6地点）  │  ← 第一幕クリアまで霧で隠す
    │  連合本陣 ─ 連合本陣前 ─ 高地   │
    │  大聖堂 ─ 街道の砦 ─ 隣国国境  │
    ├──────────────────────┤
    │  王都 ★（勇者）               │
    │  王都城門                     │
    │  大平原                       │
    │  城塞都市                     │  ← 第一幕8地点。道が蛇行しながら上へ
    │  大神殿                       │
    │  関所                         │
    │  街道                         │
    │  村はずれ                     │
    ├──────────────────────┤
    │  城下町（施設6の区画）          │  ← 魔王城のまわり
    │  🏰 魔王城                    │
 下 └──────────────────────┘
```

- 幅 390px、高さ約 2200px（背景1枚。2段階の解像度：780×4400 と 390×2200）。
- 地点は道の上に**丸い印＋名前**。第一幕8、第二幕6。間隔は 180px 前後で指が迷わない。
- 最初に開いたときは**次に戦う地点**が画面の中央に来るようスクロール位置を合わせる。

## 3. 状態の見せ方（5つだけ）

| 状態 | 見た目 |
|---|---|
| 未到達 | 灰色の印、名前は薄い |
| 前哨戦済（`st.outpost.cleared`） | 印の半分が魔王軍の色、小さな旗が1本 |
| 領地（`conquest` より下） | 印と周りの土地が魔王軍の色（紫がかった赤）に染まる。名前の横に「税 2G」 |
| 荒らされた（`st.lastRansacked`） | 領地に煙の小物を1つ重ねる。次の決着で消える |
| 防衛戦が来る道 | 王国側から城への道に点線。作戦カードに防衛戦が出ている間だけ |

城下町の施設6（市場・酒場・鍛冶場・研究所・宿舎・工場）：
- Lv0 は空き地（杭と縄）。Lv1 で建物、Lv2 で屋根がもう一段、Lv3 で看板と旗。差分は**この程度に留める**。
- タップで既存の「建てる」ボタン（`town_ui.js` の1件）を開く。銀行は魔王城の隣に金庫の絵、タップで借りる／返す。

HUD は変えない。地図の最上部に既存の一行「税 6G/決着・借金 20G」を再掲するだけ。

## 4. 画面遷移

```
城メニュー ─「城下町」札 ─▶ 地図（この文書）
   地点タップ ──▶ その地点の作戦カード（既存の作戦会議。次の地点以外は「まだ遠い」と灰色で押せない）
   施設タップ ──▶ 建てる（既存 town_ui の建設ボタン）
   金庫タップ ──▶ 魔界銀行（既存）
   「メインに戻る」（既存の home ボタン）
```
面接→作戦→編成→戦闘→結果の流れは**変えない**。地図は「眺めて選ぶ入口」。地図を開かなくても今までどおり遊べる。

## 5. 絵の枚数（合計 43 枚。多ければ (c) を削る）

| 何 | 枚数 | 仕様 |
|---|---|---|
| 背景（道・地形・城下町の区画・霧） | 1（2解像度） | 縦長 WebP。地点と施設の座標は `src/data/map.js` に数字で持つ |
| 地点の印 | 3（未到達／領地／前哨済） | 64×64 透過 WebP。名前は文字で載せる（絵に文字を入れない） |
| 施設 | 6×4 段階 = 24 | 128×128 透過 WebP。Lv0 は共通の空き地1枚でよいので実質 19 |
| 小物 | 5（旗・煙・点線・金庫・勇者の星） | 64×64 透過 WebP。点線は CSS でもよい |
| 霧 | 1 | 半透明の帯。第二幕の上に重ねる |
| 魔王城 | 1 | 192×192。既存 `hall.webp` の外観として新規 |

生成プロンプトの共通部：「太いインクの線、くすんだマットな色、90年代の怪物図鑑の地図の見開き、見下ろし、余白は透過」。

## 6. 作る順（各段階で遊べる状態を保つ）

- (a) 背景＋地点の印＋領地の色＋税の表示（絵4枚）。**これだけで「どこまで取ったか」「金はどこから」が見える**。
- (b) 城下町の施設 Lv 差分（19枚）。建てると絵が変わる。
- (c) 小物と動き（旗がなびく、煙が上がる、点線が流れる）。低モーション設定では静止。

## 7. 実装の見取り図（run.js は触らない）

- `src/data/map.js`（新）：地点14の `{ id, stage, name, x, y, act }`、施設6の `{ id, x, y }`、金庫と城の座標。
- `src/ui/map.js`（新）：`Map.render(st)`。読むのは `st.conquest`／`st.outpost`／`st.lastRansacked`／`st.town.buildings[*].lv`／`st.town.debt`／作戦カードに defend があるか。**書き込みはしない**。タップは既存の `data-action` を発火するだけ（`mission`／`townbuild`／`townborrow`）。
- `src/ui/town_ui.js`：札の先頭に地図を差し込む（施設一覧はそのまま下に残す。文字で確認したい人のため）。
- `src/battlefield.css` ではなく `src/styles.css` に `.world-map` を追加。
- ブラウザテスト `tools/browser-tests/map.js`：征服度3・前哨済・市場Lv2 のセーブで、印の色・旗・施設の絵・税の表示が出る。横スクロールが無い。

## 8. 落とし穴
- 第二幕の地点名は `enemies.js` の `region` を正とする（隣国国境・街道の砦・大聖堂・高地・連合本陣前・連合本陣）。
- 地図の座標を絵に埋めない。背景を描き直しても座標だけ直せばよいように。
- 旧セーブ：`town` や `outpost` が無くても描けること（無ければ空き地・未前哨）。
- 画像は合計で 400KB を目安。背景を 2 解像度にするのはスマホの読み込みのため。
