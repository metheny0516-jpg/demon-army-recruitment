# 仕様：王国の反撃——防衛戦のリズム（2026-09-10・設計案）

**まだオーナー未決裁の設計案。** 末尾「決めてほしいこと」に答えが出てから実装者向けに確定する。
担当（予定）：Opus。種族技 C・D と全滅後の再建（`SPEC_WIPE_REBUILD`）の後。`run.js` の作戦会議と決着処理を触る。

## 0. 一文で

**王国は黙っていない。** こちらの動き（略奪・進軍・城の接収）で王国の警戒が溜まり、閾値を超えると討伐隊が城へ来る。次の作戦会議は「城を守る」一択になる。守れば警戒が下がり名が上がる。守れなければ城が荒らされる（施設・食料・蔵の遺物）。

これで戦いは「攻める番」と「守る番」を交互に迎える。採用は「欠員補充」から「次の反撃に備える」になり、留守番の仕事（城の備え）に意味が出る。撤退・負傷・戦死・継承・種族技は全部この圧力の下で回る。

## 1. 目的と、やらないこと

目的：
- 敵が攻めてこない（設計会話 2026-09-10 のずれ①）を直す。進軍のタイミングと人材の入れ替えが急かされる。
- 警戒度（`st.alert`）に意味を持たせる。今は敵の能力 +2%/pt にしか効かず、プレイヤーに見えない。
- 開幕3日目の勇者襲来を「最初の反撃」として同じ仕組みに乗せる（別物にしない）。

やらないこと：
- 王国側の内政・外交・和平。
- 捕虜・行方不明（LP の仕様）。
- 城の攻防の専用戦闘（城壁・門・籠城）。防衛戦も通常の戦闘で、違うのは相手と結末だけ。
- 討伐隊の固有人物・脚本。名前と編成は段階表とバリエーションから作る。

## 2. ルール（案）

### 2.1 時計＝警戒度

`st.alert` を時計にする。**新しいパラメータは作らない。**

| 出来事 | 警戒度 |
|---|---|
| 略奪に勝つ | +2（既存） |
| 鎮圧に勝つ | +1（既存） |
| 進軍に勝つ | **+2（今は0。ここを変える）** |
| 撤退・判定負け・全滅 | +1（既存の撤退と同じ） |
| 城の接収 | +既存の `SEIZE_ALERT_COST` |
| 防衛戦に勝つ | **−閾値ぶん**（0まで） |
| 防衛戦に負ける | −閾値の半分（荒らして満足して帰る） |

閾値 `COUNTERATTACK.threshold` は **6** から試す（略奪3回、または進軍2回＋略奪1回で来る）。**揺らぎ**：閾値到達の判定は「警戒度 ≥ 閾値 − 1 で 50%、≥ 閾値で必ず」。規則的すぎない程度に（ChatGPT の指摘）。

### 2.2 予告と一択

警戒が閾値に達した決着の直後、モルモが報告する（結果画面前の `battleReport` に一言追加。「魔王様、王国が討伐隊を出しました。次は、こちらへ来マス」）。
**次の作戦会議は「城を守る」一択**（`MISSION_TYPES` に `defend` を足し、`prepareMissions` が反撃予約中はこれだけを出す）。作戦カードには討伐隊の名と編成のヒント（既存の `hint`）。
予告は必ず1手番前。奇襲はしない（採用と編成で備える時間を作るのが目的）。

### 2.3 討伐隊

敵は段階表を **魔王軍レベル＋1** で引く（`enemyTierOffset: +1`、`enemyMult: 1.0`）。進軍より一段強い。バリエーションから引き、隊の名は「{段階の army}討伐隊」。
最終段階（勇者アレン一行）は討伐隊にしない（最終戦は進軍でだけ起きる）。魔王軍レベル8で反撃が来たら段階7（聖騎士団）を使う。

### 2.4 結末

- **勝つ**：警戒度 −閾値。報酬は無い（守っただけ）が、**押収**で建材 +2・食料 +2。次の面接の応募者 +1（名が上がる。`applicantCount` に一時加算）。魔界史に「{討伐隊}を退けた」。
- **撤退**：城を明け渡して山へ逃げる扱い。倒れた者は担いで帰る（負傷）。**荒らされる**（下）。警戒度 −閾値/2。
- **判定負け**：撤退と同じ。
- **全滅**：`SPEC_WIPE_REBUILD` のとおり出撃隊は戦死。さらに荒らされる。

**荒らされる**（`ransack`）：施設レベル −1（`buildProgress` はその段階の閾値に戻す）、食料半減、**蔵の遺物を1つ持ち去られる**（あれば。名前を控えて、後の討伐隊が「{name}の杯」を持って現れる余地を残す＝痕跡。今は持ち去るだけ）。留守番は無事（人は取らない。LP の仕様で捕虜を扱う）。

### 2.5 開幕の勇者襲来

開幕3日目の防衛戦を、**この仕組みの最初の1回**にする：`newRun` で `alert` を閾値に置き、日目3に `defend` が出る。今の `prepareOpeningBattle("invade")` は `defend` に置き換える。文言（「勇者到着まであと2日」）はそのまま。結末も 2.4 と同じ（開幕で負けると荒らされて始まる。それも歴史）。

### 2.6 sim の戦略

`tools/sim.js` の戦略は作戦を選ぶとき `defend` が一択なら受けるだけ。「略奪4回→侵攻」は反撃で中断される（狙いどおり）。

## 3. 表示

- HUD の警戒度に「反撃まで」の目安（`alert / threshold` の小さなゲージ。数字は出さない。閾値−1 で赤）。
- 作戦会議：`defend` カードだけ。見出し「{討伐隊}が城へ向かっている」。
- 結果画面：勝てば「城を守った」、負ければ「城が荒らされた：施設Lv−1、食料半減、{遺物}を奪われた」。
- モルモ：予告（2.2）、勝利「守りましたデス！ 王国は当分おとなしいはず」、敗北 worried「……蔵が、荒らされました」。

## 4. 契約（案）

- `MISSION_TYPES.defend`（`missions.js`）。`st.counterattack = { pending: bool, armyName, dueTurn }`。`st.ransackCount`。
- `Game.checkCounterattack()`（決着処理の最後。閾値判定と予約）、`Game.ransack(notes)`。
- 魔界史 record に `defenses: { won, lost }`（主要記録は増やさない）。
- battle.js は触らない。

## 5. 受け入れ条件（案）

- テスト：警戒6で予約→次の作戦会議が `defend` 一択→勝てば警戒0・押収・応募者+1／撤退で荒らされる（施設−1・食料半減・遺物−1）／全滅で戦死＋荒らされる。開幕3日目が `defend` になる。閾値−1 の50%が `U.chance` 固定で再現する。
- sim：実装前後3回。合格帯なし（系統的に動く）。報告：平均クリア率、平均戦闘数、防衛戦の回数と勝率、荒らされた回数。「略奪4回→侵攻」が 0% なら締めすぎ。
- browser-tests：予告→一択→結果画面→HUD のゲージ。

## 6. 決めてほしいこと

1. **時計は警戒度でよいか。** 代案は「進軍に勝つたび必ず次に反撃」（規則的、予告不要）。私は警戒度案を推す。略奪を繰り返す遊び方に自然な圧力がかかり、既存の数値を使える。
2. **負けたときに失うもの。** 案：施設Lv−1・食料半減・蔵の遺物1つ。人は取らない。もっと軽く（食料だけ）か、重く（留守番1人が捕虜）か。
3. **防衛戦の出撃隊。** 案：通常と同じ5人。代案：城にいるので留守番も戦う（人数無制限、留守番は半額手当のまま）。後者は「留守番が意味を持つ」が強まるが、戦闘が大きくなり sim の前提が変わる。私は今回は5人、留守番参加は LP の後。
4. **開幕の勇者襲来を同じ仕組みに乗せるか。** 案：乗せる（最初の反撃）。
