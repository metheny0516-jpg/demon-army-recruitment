# 設計：城下町の経済 ― 税で回し、借金で波乱（2026-09-12）

オーナー決定：
- **難しくしない**（将来は中高生にも遊んでほしい）。
- 主収入は**税収**。採用の契約金は入れない（採用コストは今のままで十分高い）。
- **借金あり**。
- 入口は城メニューの新しい札「城下町」。当面はテキスト中心。並行して、城下町を含む**全体マップの見た目**（立体風か SFC 並みの 2D）を CodeX に設計させる。
- 数字の詰め方は Claude に任せる（sim は煙探知：破産率・最終所持金・施設到達だけ見る。手触りは試遊）。

## 0. 一文で

**取った領地から税が入り、その金で城下町に投資し、投資が軍団を強く・安くする。足りなければ魔界銀行から借りる。**
覚えることは3つだけ：「領地＝税」「施設＝投資」「借金＝利子」。

## 1. お金の環（プレイヤーに見せる形）

```
 進軍で領地を取る ──▶ 税収（決着ごと）──▶ 城下町に投資 ──▶ 軍団が強く・安く ──▶ さらに進軍
        ▲                                     │
        └──── 足りないとき：魔界銀行で借りる（利子）◀┘
```

家計簿（決着ごとに1枚、モルモが読む）：**入り**＝報酬・略奪・税収／**出**＝給与・食料・建設・利子。赤字なら赤く、モルモが一言。

## 2. 税収（主収入）

- 領地＝本戦で取った段階（`st.conquest`）。**1領地につき決着ごとに 2G**（第二幕の領地は 3G）。段階4なら 8G。
- 領地は**荒らされる**ことがある：防衛戦に負けると、その決着の税収は 0（既存の「荒らされた」に乗せる。新しい仕組みは足さない）。
- 市場（施設）で税率が上がる（3節）。
- 表示：HUD の「王国攻略 3/8」の横に「税 6G/決着」。

## 3. 城下町の施設（6つ。今の3施設は「戦闘の施設」として残す）

建てるには**金と建材**。人手は要らない（今の「施工」は建材を運ぶ仕事として残す）。Lv1〜3。**効果は一文で言えるものだけ**。

| 施設 | Lv1 の値段 | 効果（Lv ごとに一段） | 一文 |
|---|---|---|---|
| 市場 | 15G・建材3 | 税収 +1G／領地（Lv3 で +3） | 「領地の税が増える」 |
| 酒場 | 12G・建材2 | 留守番の忠誠回復 +3／決着。Lv2 で応募者の希望給与 -1、Lv3 で -2 | 「みんな機嫌がよくなる。安く雇える」 |
| 鍛冶場 | 20G・建材4 | 出撃隊の防御 +1／Lv | 「硬くなる」 |
| 研究所 | 25G・建材3 | 種族技を覚える戦闘数 -1／Lv（3戦→2戦→1戦）。Lv3 で上位技も -2 | 「技を早く覚える」 |
| 宿舎 | 10G・建材5 | 軍団の上限 +1／Lv。負傷の回復が1決着早い（Lv2〜） | 「もっと雇える。早く治る」 |
| 工場 | 15G・建材2 | 建材 2 → 金 3 の両替を決着ごとに Lv 回まで（押すだけ） | 「余った建材を金に」 |

- **職業一致**：留守番にその施設に合う職業の者がいれば、**建てる値段が2割引**（会計→市場、料理人・呼び込み→酒場、石工・鍛冶→鍛冶場、備品・経理→研究所、倉庫番・配達→工場、誰でも→宿舎）。効果は変えない（難しくしない）。裏方の職に居場所を作る。
- 建てるのは城下町の札から。**1決着に1件**（迷わせない）。建設は即時（待たせない）。

## 4. 魔界銀行（借金）

- 城下町の札に「魔界銀行」。**借りる：10G・20G・30G の3択**。利子は**決着ごとに借入額の 10%**（10G 借りたら毎決着 1G）。
- 返す：いつでも全額か半額。返せば利子は止まる。
- 借入残高の上限は 50G。**返せないと**：所持金が 0 でも利子が払えないとき、モルモが「差し押さえ」を宣言し、**城下町の施設が1つ Lv を1落とす**。人は取られない（「人ではなく時間と圧力で払わせる」の原則）。
- 表示：HUD に「借金 20G（利子 2G/決着）」。
- 銀行員は魔物（ミミックの親戚）。台詞はくすっと。

## 5. 触るもの（実装のときの見取り図。今は設計だけ）

- データ：`src/data/town.js`（新）：施設6・銀行・職業一致・値段。
- run.js：税収（`applyMissionOutcome` の隣）、建設、両替、借入・返済・利子、差し押さえ、家計簿（`st.ledger`：決着ごとの入り出）。
- UI：城メニューに「城下町」札（施設一覧・建てる・銀行・家計簿）。HUD に税と借金。
- sim：戦略に「城下町に投資する」を1つ足し、破産率・最終所持金・施設到達を列に。
- 旧セーブ：`town` が無ければ空。

## 6. やらないこと（難しくしないために）

- 契約金、人件費の階層、物価の変動、商品の売買、施設への人員配置、施設同士の相性。
- 施設の効果は一文で言えないものを作らない。数字は3段階まで。
