## 2. 見えたこと

- **Opus は仕組みから、CodeX は物語から**出している。Opus の案は全部「作戦会議か城下町に一手」で済み、CodeX の案は半分が「条約・講和・占領」という**まだ無い仕組み**に寄る。
- CodeX の強みは**殿堂の一行**。「経理の○○が、敵の一個中隊に給料を払った」「王国を取った魔王は、町の株主総会に呼ばれた」は、そのままゲームの宣伝文になる。仕組みは Opus 案、言葉は CodeX 案、という組み合わせが効く。
- **合わせ技**にすると強くなるもの：
  - 経済征服（`BIG_ARCS` 2節）＝ CodeX 1「給料日」を最初の一歩に、CodeX 7「共同出資」を中盤に、着地は 2節の「王都を買う」。
  - 訓練場の続き＝ Opus 2「鬼教官」＋ Opus 8「捕虜」で、訓練場の4段目と教官が同時に入る。
  - 痕跡の続き＝ CodeX 5「裏門」＋ Opus 7「語り部」で、痕跡が「攻略順」と「読み物」の両方に効く。
