# 仕様：指示待ちの決めポーズと、行動の構え（2026-09-15）

オーナー：「格好よく指示を待つポーズ」と「決めた行動を実行するための構え」を分ける。
登場動作から決めポーズへ → その姿のまま吹き出しで指示 → 選んだ行動の構え → 全員が決めたら実行。
最初は本人らしい見栄や格好よさ、指示後は選んだ行動への意志と緊張感、の二段階。
**登場動作と吹き出しはほぼ同時に出す。2周目以降も省略しない（大事なパートなので）。**

## 0. 分担と触るファイル

| 担当 | 触るファイル | 触らない |
|---|---|---|
| CodeX（絵） | `assets/battle/units/<race>/ready.webp`、`assets/battle/units/<race>/guard.webp`（下記18種） | src/ 以下すべて |
| Opus（配線） | `src/ui/battle_scene.js`、`src/styles.css`、`tools/browser-tests/art-coverage.js`、`tools/browser-tests/order.js`（または新規 `command-pose.js`） | `src/core/run.js`、`src/core/battle.js` |

順番：**CodeX の絵が18種そろって本線に入ってから Opus の配線**。絵が無い種族に `ready` を登録すると 404 で autoplay が落ちる（マンドラゴラで踏んだ）。
絵と `BATTLE_SPRITES` の登録は同じコミットにする（Claude が取り込み時に行う）。

## 1. 絵（CodeX）

対象は**指示を受ける側＝採用できる18種**だけ。敵専用（勇者一行・反乱軍・隊長・騎兵など）は不要。

| id | 種族 | 決めポーズ `ready` の一言 | 防御の構え `guard` の一言 |
|---|---|---|---|

- 形式：既存の6枚と同じ **512×512・透過 webp**。`assets/battle/README.md` の生成指針（荒い線・抑えた影・格好つけすぎない）に従う。**ゴブリンの得意げ、ゾンビの遅さのように、種族の性格が出る雑さを残す**（設計原則の「全員が完璧なポーズ」を避ける）。
- 同じ種族の `idle` と同じ体格・同じ接地線。`motion-source.png` がある種族はそれから起こす（マンドラゴラだけ無い。`idle.webp` を元にする）。
- `ready` は「動作の終わり」の姿。登場動作そのもの（回る・跳ねる）は絵ではなく配線側の transform で見せるので、**止まった姿だけ**描く。
- 攻撃・技の構えは既存 `attack-windup` を使うので描かない。
- ブランチ `codex/command-pose-art`。commit は種族ごとでも18種まとめてでもよい。上がったら Claude が `BATTLE_SPRITES` に `ready` `guard` を足し、`art-coverage` の枚数を 210 → **246**（＋18種×2）にして取り込む。

## 2. 配線（Opus）

指示窓（`renderCommandPanel`、ロマサガ流）の各状態と絵の対応：

| 状態 | 既存クラス | ポーズ | 動き（transform / opacity だけ。設計の約束 2-2） |
|---|---|---|---|
| 指示の番が来た | `cmd-active` | `ready` | **登場動作**：0.375 秒（09-16：0.25 では見逃すので 1.5 倍）で「小さく跳ねて半回転→戻る」か「ぐっと前へ出て戻る」のどちらか（種族で分けなくてよい。1種類でよい）。動作の開始と同時に吹き出しを出す（待たない）。 |
| 選択中 | `cmd-active` | `ready` のまま | 静止 |
| 決めた：たたかう／技 | `cmd-decided` + `data-cmd` | `attack-windup` | 決めた瞬間に 0.15 秒で切り替え（opacity のクロスフェードでよい） |
| 決めた：まもる | `cmd-decided` | `guard` | 同上 |
| 決めた：食べる／おまかせ | `cmd-decided` | `idle` | 切り替えだけ |
| 「もどる」で戻された | `cmd-active` | `ready` | 登場動作をもう一度やってよい |
| 全員決めて実行開始 | （クラスは外れる） | **構えを保つ**。攻撃演出は `attack-windup` から始まるので、そのまま `strike` へつながる。`guard` は自分の手番（`guard` の記録イベント）か次ラウンドの指示まで保つ | ― |

- **2周目以降も同じ**。省略・短縮の分岐を作らない。
- 登場動作は `animateActor` を使う。`prefers-reduced-motion` では静止で `ready` だけ出す（既存と同じ扱い）。
- `hideCommandPanel` で `idle` に戻している箇所があれば、**戻さない**（構えを保つのが要件）。倒れている者は `fallen` のまま。
- `BATTLE_SPRITES` に `ready` `guard` が無い種族（敵専用・魔王）は `setPose` が何もしないので、そのまま idle でよい。分岐は不要。
- `CMD_ICON` の印（⚔🛡✨）は今のまま残す。構えと印は両方出る。
- テスト：`tools/browser-tests/order.js` に2件（または新規 `command-pose.js`）：
  1. 指示の番が来た味方の `sprite.dataset.pose` が `ready`、決めた後は `attack-windup` / `guard`。
  2. 全員が決めて実行に入った直後、攻撃を選んだ者の pose が `idle` に戻っていない。
- `art-coverage.js` の期待枚数は Claude が絵の取り込み時に 246 にする。Opus は触らない（衝突を避ける）。
