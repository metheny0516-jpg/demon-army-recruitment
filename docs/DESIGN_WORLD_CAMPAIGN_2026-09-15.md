# 設計：地図の上の戦争 ― 落とす場所を選び、統治外の魔物を従える（2026-09-15、Claude 起草・大枠・オーナー判断待ち）

オーナー（2026-09-15）：「もっと大きなくくりで。略奪といっても辺境の村から橋、集落、峠、山村、砦、港、町、都と様々あるから、次はここを落とす、と計画したり。反乱も、魔王軍統治外の魔物たちがたくさん周りにいて、その中に首領がぽつぽついる。マップをからめた壮大な設計に」。

姉妹文書：`DESIGN_CAMPAIGN_ROUTE_2026-09-15.md`（三本の糸＝人物の話。この文書の上に乗る）、`WORLD_MAP_DESIGN_2026-09-13.md`（今の地図＝段階1〜14を縦に並べた一本道）。

## 0. 一文で

**地図を「段階の列」から「土地の面」に変える。人間界には落とす場所が二十ほどあり、魔界の周りには魔王軍の外にいる魔物の部族が十ほどいる。プレイヤーは決着ごとに「次はどこを落とすか／どの部族を従えるか」を地図で選び、落とした土地と従えた部族が軍団の顔ぶれと収入と守りを変える。**

「魔王ワーク」の主題との接続：**部族を従えるとは、その種族が履歴書を持って来るようになること**。征服が採用につながる。

## 1. 世界の形（1画面・縦スクロール1本は今のまま）

```
        ┌── 人間界（北）──────────────────┐
        │  王都 ═ 都(第二の都)                 │  ← 幕の着地
        │  町 ─ 砦 ─ 大神殿 ─ 港              │
        │  峠 ─ 山村 ─ 橋 ─ 集落 ─ 関所        │
        │  辺境の村 ─ 街道 ─ 渡し場            │  ← 最初の三つ
        ├── 国境 ────────────────────────┤
        │  魔界（南）                          │
        │  [ゴブリンの丘] [沼のスライム] [骨の谷] │  ← 部族圏（統治外）
        │  [ハーピーの断崖] [オークの荒野] …    │
        │        魔王城 ・ 城下町 ・ 訓練場      │  ← 今のまま
        └──────────────────────────────┘
```

- 人間界の土地は**種類**を持つ（8種類）。種類が「落とすと何が起きるか」を決める。
- 魔界の部族圏は**種族**を持つ。首領が一人ずついる（全部ではない。「ぽつぽつ」）。
- 土地と部族圏は線でつながる（隣接）。**落とせるのは今の領土に隣接する場所だけ。** 計画とは「どの線を伸ばすか」。

## 2. 土地の種類（人間界・8種類）

| 種類 | 例 | 守り | 落とすと（土地の効き目） | 王国に奪い返されると |
|---|---|---|---|---|
| 村 | 辺境の村・山村 | 弱 | 食料 +（毎決着） | 食料が止まる |
| 集落・渡し場 | 集落・渡し場 | 弱 | 応募者 +1（人間の傭兵が混ざる） | ── |
| 橋・峠 | 橋・峠 | 中 | **進路が開く**（向こう側の土地が隣接になる） | 向こう側が切れる |
| 関所・砦 | 関所・砦 | 強 | 防衛戦が城の手前で起きる（城下町が荒らされない） | 防衛線が消える |
| 港 | 港 | 中 | 金 +（毎決着）・両替の率が良くなる | 金が止まる |
| 神殿 | 大神殿 | 強 | 王国の討伐隊が薄くなる（僧侶が来ない） | 討伐隊に僧侶が戻る |
| 町 | 城塞都市・町 | 強 | 応募者 +2・給与相場が下がる・**顔役の糸が進む** | 応募者が減る |
| 都 | 王都・第二の都 | 最強 | **幕の着地**（今の「攻めた」） | ── |

- 一つの土地の効き目は**数字1本**（施設の詳細画面と同じ約束）。
- 略奪は「落とさずに殴って帰る」。同じ土地に対して**落とす（統治）か、略奪（一回の金）か**を選べる。略奪した土地は警戒が上がり、次に落とすとき守りが硬い。
- 今の段階1〜8の敵隊列は**土地の守備隊**として使い回す（村＝段階1〜2、橋・峠＝3、砦・神殿＝4〜5、町＝6、都＝7〜8）。敵データは増やさない。

## 3. 魔界の部族（統治外の魔物・10ほど）

| 部族圏 | 種族 | 首領 | 従えると |
|---|---|---|---|
| ゴブリンの丘 | ゴブリン | 自称将軍ザガン（`DESIGN_CAMPAIGN_ROUTE` の顔役） | ゴブリンの応募が増える・集団戦法の技を持つ者が来る |
| 沼 | スライム | なし | スライムの応募・食料少し |
| 骨の谷 | 骸骨兵・ゾンビ | 「墓守」 | 墓地の効き目が上がる |
| 断崖 | ハーピー | なし | 偵察（前哨戦なしで隊列が見える土地が増える） |
| 荒野 | オーク | 「血の族長」 | オークの応募・血の雄叫び |
| 鉱山 | コボルト | なし | 建材 + |
| 森の奥 | マンドラゴラ・トロル | 「長老」 | 回復役の応募 |
| 廃墟 | インプ・死霊術師 | 「塔の主」 | 術士の応募 |

- 部族との決着は三択：**討つ／従える（戦って勝ってから）／贈る（金と食料で従える。戦わない）**。従えた部族圏は領土になる。
- 首領がいる部族は「反乱」の糸の相手。放っておくと首領が周りの部族をまとめ、**魔界側から攻めてくる**（今の「反乱鎮圧」がこれになる。統治外の魔物が魔王城を狙う）。
- 従えた部族は**その種族の応募者が毎決着 1 人混ざる**。これが征服の一番の報酬。「うちの軍団がゴブリンだらけなのは、最初にゴブリンの丘を従えたから」が語れる。
- 首領は雇える（`DESIGN_CAMPAIGN_ROUTE` の「雇う」）。

## 4. 決着ごとの選択（3枚＋訓練は今のまま）

3択の中身が「種類の固定」から**「地図上の候補」**になる：

```
🟢 辺境の村を落とす      守り：弱（自警団）      食料 +2／決着     警戒 ▲
🟡 橋を落とす            守り：中（⚠ 隊長ボルドがいる）  峠の向こうが開く   警戒 ▲▲
🟢 沼のスライムを従える  相手：スライムの群れ     スライムの応募     警戒 なし
```

- 候補は**隣接する未領土**から3つ。人間界2＋魔界1、か、人間界1＋魔界2（交互に出る）。全部人間界の日は作らない。
- 「略奪だけして帰る」は札の中の切り替え（落とす／略奪）。
- 王国の討伐隊・統治外の魔物の襲来は今までどおり予約（防衛の札）。**狙われる土地が地図に出る**（「関所へ討伐隊が向かっている」）。守り切れないとその土地が戻る。
- 訓練の札は今のまま。

## 5. 三本の糸との接続（`DESIGN_CAMPAIGN_ROUTE`）

- 村の糸（ポルカ）＝**村・集落の土地**で起きる。落とすたび立つ。
- 魔界の糸（ザガン）＝**ゴブリンの丘の首領**。首領を放置すると部族をまとめて攻めてくる。
- 王国の糸（ガレス）＝**砦と都**の守備隊長。砦の関門、都で勇者の隣。
- 最終戦（都）の勇者一行の顔ぶれは「討たなかった者」で決まる（同文書 2節）。

## 6. 中高生にも遊べる簡単さを崩さないために

- 画面は今の地図のまま。**タップできる場所は光っている3つだけ**（隣接の候補）。地図全体を眺めるのは自由だが、選ぶのは3つ。
- 土地の効き目は一行で言い切れるものだけ（「食料 +2」「橋の向こうが開く」）。
- 数は上限を決める：人間界 20 土地、魔界 10 部族圏、第一幕はそのうち人間界 10・魔界 5。第二幕で残りが開く。
- 一回のランで全部を落とす必要はない。都に届けば幕は終わる。**「どこを通ったか」がランごとに違う**のが狙い。

## 8. 触るものの見取り図（段階 A）

- `src/data/map.js`：地点を「土地」に（id・種類・隣接・守備隊の段階・効き目）。
- `src/core/run.js`：`genMissionOffers` が隣接候補から3枚を作る。`st.territory = Set(土地id)`。決着ごとの効き目の加算。`st.conquest` は領土の数から導く（互換）。
- `src/ui/map.js`：領土の色、候補の光り、タップで札へ。
- `tools/sim.js`：戦略に「近い順に落とす」「港を先に」など2本足す。
- battle.js は触らない。

## 9. やらないこと

- 部隊を複数動かす（軍は一つ。出撃隊は一隊）。
- 土地ごとの詳細画面（施設の詳細画面と同じ型で後からでよい）。
- 外交・条約・同盟。「贈る」は一回きりの取引で、状態を持たない。
- 地図の横スクロール。縦1本のまま。

## 10. オーナー判断

1. 規模：人間界 20・魔界 10 でよいか（第一幕は 10・5）。少なくするなら 14・7。
2. 部族の三択に「贈る（戦わずに金と食料で従える）」を入れるか。**推奨は入れる**（戦闘以外の手が一つあると計画になる）。
3. 段階 A から着手してよいか。A は run.js が中心（Opus）で、決めポーズ・大技・施設詳細の後になる。**先に土地20＋部族10の名前と種類の一覧（データ）を私が作り、CodeX に絵の目安を渡す**、が並行できる最初の一手。
