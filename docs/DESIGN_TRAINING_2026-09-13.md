# 設計：訓練場 ― 展開と無関係に鍛える場所（2026-09-13、オーナー方針を反映した第2版）

オーナー決定（2026-09-13 夜）：
- **回数制限なし**。新しい技や新種族の試し打ちに制限があるのは変。
- 代価は**食料だけ消費、給与は半分**。
- 段階的に解放し、相手の強さも上がる。ただし**仕上がった軍団には旨味がない**もの（金は入らない）。
- 勇者に全滅させられて組み直したとき「誰も技を覚えていない」不安を消す、**エキシビション**（展開に無関係）の場。

## 0. いまの「育つ」の仕組み（確認）

| 何が伸びる | どうやって | 上限 |
|---|---|---|
| HP・攻撃・防御（小成長） | 出撃した戦闘数 × 割合 | `growthCapBattles` で止まる（既にある） |
| 技 | 種族技3戦・上位技8戦 | 開けば終わり |
| 戦功→将軍 | 生存・撃破・最多与ダメ | 22 で転身 |
| 気合 | 決着ごと +1 | 上限3（鍛冶場で+） |

小成長も技も**天井がある**ので、訓練を無制限にしても「無限に強くなる」ことはない。仕上がった軍団が訓練しても、得るのは気合と忠誠だけ。これが「旨味がない」の中身。

## 1. 一文で

**城の脇に訓練場。いつでも何度でも練習試合ができる。死なない、金も建材も入らない、王国には知られない。食料は減り、給与は半分出る。育つものは本番と同じ。**

## 2. 規則

### 2.1 入口
- 作戦会議の4枚目のカード「訓練」。防衛戦が出ている決着でも出す（勇者が来る前に鍛え直す場でもある）。
- 地図では城の脇に「訓練場」の地点（絵は CodeX）。タップで同じカードへ。

### 2.2 相手（段階解放）
| 相手 | 解放 | 中身 |
|---|---|---|
| 案山子隊 | 最初から | 今の征服度の本戦の隊列を写し、HP・攻撃 0.6 倍。役はそのまま |
| 模擬戦 | 征服度 2 以上 | 本戦の隊列そのまま（前哨済なら本戦と同じ顔ぶれ＝予行演習） |
| 猛者 | 征服度 4 以上 | 隊列に「隊長」を1体足し、HP・攻撃 1.2 倍。将軍を狙う者の稽古 |

- 3つのうち解放済みから選ぶ（カードに3つの小ボタン）。迷わせないため既定は「いま一番強いもの」。
- 敵は殺しに来ない：HP 0 は**戦死ではなく負傷**（次の1戦出られない）。撤退はいつでもでき、担ぐ処理は無い。

### 2.3 入るもの・出るもの
| | 訓練 | 参考：略奪 |
|---|---|---|
| 金・建材・遺物・痕跡 | **無し** | あり |
| 食料 | 戦闘糧食を消費（普通どおり） | 得る |
| 給与 | **半分**（端数は切り上げ。未払いの判定も半額で） | 全額 |
| 税収・利子 | 税収**無し**、利子は普通どおり | 税収あり |
| 警戒度 | +0 | 大きく上がる |
| 戦闘数（小成長・技） | **+1**（本番と同じ。天井は既存のまま） | +1 |
| 戦功 | 生存 +1 のみ（撃破・最多は数えない。猛者なら +2） | 通常 |
| 気合 | 通常どおり | 通常 |
| 忠誠 | 出撃隊 +1 | 通常 |

- 「1決着」として進む（給与・利子・城下町の酒場などの決着処理は通る。税収だけ 0）。
- 種族技も上位技も**訓練だけで開けてよい**（オーナー決定）。8戦ぶん食料と半給を払うのが代価。

### 2.4 なぜ暴れないか
- 金が1円も入らないので、訓練を続けるほど懐は細る（給与半額＋利子）。
- 小成長は `growthCapBattles` で止まる。技は開けば終わり。将軍は生存 +1 ずつなので訓練だけなら 22 戦要る（猛者で 11 戦）。
- sim で見るのは「訓練の使用率」と「破産率」だけ。使用率が 1ランに 0 なら忠誠 +1 を +2 に、破産率が 5 ポイント上がれば給与を 1/3 に。

### 2.5 見せ方
- カード：「訓練：案山子隊と練習試合」「模擬戦：本戦の顔ぶれで」「猛者：隊長つきの稽古」。一行「死なない。金は入らない。食料と半分の給与」。
- 戦闘中は敵の札に「稽古」の帯。勝っても歓声は鳴らさず、短い拍手（CodeX に1本、`train-clap.wav`）。
- 結果：「稽古を終えた。○人が一回り強くなった／○人が技を覚えた」。倒れた者は「負傷」。
- モルモ：初回「体を動かすのは大事デス。金は減りますが」、猛者解放「隊長つきの相手を用意しましたヨ。将軍の稽古デス」。

## 3. 触るもの（統合と将軍が入ってから。Opus）
- `src/data/missions.js`：`train` の型（3つの相手・descriptions・strategyHint）。
- `src/core/run.js`：`buildMission` に4枚目、相手の生成（既存 formation を写して倍率、猛者は commander 追加）、決着で `training: true` のとき金・建材・遺物・痕跡・税・警戒度を飛ばし、戦死→負傷、戦功の別計算、給与半額、忠誠 +1。
- `src/ui/ui.js`：カードの3ボタンと帯、結果文言。`src/data/mormo_lines.js` 2本。
- `src/ui/map.js`／`src/data/map.js`：訓練場の地点（絵が来たら）。
- `tools/test-training.js`（新）：死なない・金0・警戒0・戦闘数+1・技が開く・給与半額・解放の段階。`tools/sim.js` に戦略「進軍の前に訓練を1回」と列「訓練回数」。
- battle.js：**触らない**（倍率は写すときに掛ける。戦死→負傷は結果を読む側で変換）。

## 4. 落とし穴
- 訓練でも `record.battles` が進むので、痕跡（担がれ・戦友の死）が訓練で立たないよう `training` のときは痕跡の記録を止める。
- 訓練中の「かばう」「まもる」の気合 +1（`gainSpirit`）は本番と同じ。止めない（練習で技の感触を掴む場だから）。
- 防衛戦が出ている決着で訓練を選んでも、防衛戦は消えない（次の作戦会議にまた出る）。勇者の防衛戦も同じ。
