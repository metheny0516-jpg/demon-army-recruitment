# 設計：訓練場 ― 進軍せずに育てる場所（2026-09-13、Claude 起草。オーナー判断待ち）

オーナー：「略奪だけで無限に戦闘はできないし、勇者も来る。レベル上げ的な場所があれば成長しやすい。訓練場だけでやりすぎてもダメ。報酬も考えつつ」。

## 0. いまの「育つ」の仕組み（確認）

| 何が伸びる | どうやって | 上限 |
|---|---|---|
| HP・攻撃・防御（小成長） | 出撃した戦闘数 × 割合（`growthPerBattle`） | `growthCapBattles` で止まる |
| 技 | 種族技3戦・上位技8戦（`record.battles`） | 開けば終わり |
| 戦功→将軍 | 生存・撃破・最多与ダメ | 22 で転身 |
| 気合 | 決着ごと +1、留守番は +2 | 上限3（鍛冶場で+） |

つまり「戦闘数」が育ちの通貨。寄り道（略奪・鎮圧）は警戒度を上げ、進軍は本戦で負けると前哨からやり直し。**育てるために安全に戦う場所が無い**のは本当。

## 1. 一文で

**城下町の外に「訓練場」。1決着を使って、出撃隊が練習試合をする。死なない・金は入らない・警戒度は上がらないが、給与と食料は普通に出る。戻りは「戦闘数1」と少しの戦功。**

「時間（決着）を払って育てる」。金や警戒度ではなく**時間**が代価なので、借金の利子・給与・領地の税収の流れがそのまま抑えになる。

## 2. 規則

### 2.1 入口
- 作戦会議の4枚目のカード「訓練」（invade／raid／suppress の隣。防衛戦が出ているときは出ない）。城下町の地図では城の脇に「訓練場」の地点（絵は CodeX、あとで）。
- 施設ではなく**場所**。建てなくても最初からある。ただし **宿舎 Lv2 で練習相手が増え、鍛冶場 Lv2 で怪我をしなくなる**（施設の効きを1本ずつ足すだけ）。

### 2.2 相手
- 「案山子隊」：今の征服度の**本戦の隊列を1段弱くした写し**（HP 0.7、攻撃 0.7、役はそのまま）。次の本戦の顔ぶれを予習できる（前哨戦の読みと重なるので、**前哨戦済なら本戦の隊列そのまま**にして「予行演習」と呼ぶ）。
- 敵は殺しに来ない：味方が HP 0 になっても**戦死ではなく負傷**（次の1戦出られない。既存の `injured`）。撤退で担ぐ処理は要らない。

### 2.3 入るもの・出るもの
| | 訓練 | 参考：略奪 |
|---|---|---|
| 金 | 0 | 大 |
| 食料 | 戦闘糧食を消費（普通どおり） | 得る |
| 警戒度 | +0 | 大きく上がる |
| 戦闘数（技・小成長） | **+1**（ただし 2.4 の上限） | +1 |
| 戦功 | 半分（生存 1 のみ。撃破・最多は数えない） | 通常 |
| 気合 | 通常どおり +1 | 通常 |
| 忠誠 | 出撃隊 **+2**（「訓練は楽しい」。給与未払い中は無し） | 通常 |
| 建材・遺物・痕跡 | 無し | あり |
| 給与・税・利子 | 通常どおり1決着ぶん | 同じ |

### 2.4 やりすぎを止める2本
1. **訓練で数える戦闘数は1ランに 4 回まで**（`st.trainingCount`）。5回目以降は小成長も技も進まず、気合と忠誠だけ。カードに「あと2回は身につく」と出す。
2. **勇者の時計は止まらない**：訓練でも決着は進むので、王国の反撃・給与・利子は同じ速さで来る。金が増えないぶん、訓練を重ねるほど懐は苦しい。

これで「訓練だけで上位技を8戦で開く」は不可能（種族技3戦は訓練だけで開けるが、それは狙いどおり：序盤に技を見せる場所になる）。

### 2.5 見せ方
- カード：「訓練：案山子隊と練習試合」。一行「死なない。金は入らない。あと○回は身につく」。
- 戦闘中は敵の札に「案山子」の帯。勝っても歓声は鳴らさず、短い拍手（CodeX に1本）。
- 結果画面：「訓練を終えた。○人が一回り強くなった」。倒れた者は「負傷」。
- モルモ：初回「体を動かすのは大事デス。金は減りますが」、上限到達「もう案山子から学ぶことは無いデスね」。

## 3. 数字の狙い（sim で見る）
- 20ランで、訓練の使用率が **1ランに 1〜3 回**なら狙いどおり。ほぼ 0 なら忠誠 +2 を +3 に、常に 4 なら上限を 3 に。
- 破産率が 5 ポイント以上上がるなら、訓練の食料消費を半分に。
- 勝率は見ない（訓練は勝率を上げるためのものなので、上がって当然）。

## 4. 触るもの（統合と将軍が入ってから。Opus）
- `src/data/missions.js`：`train` の型（title・descriptions 3本・strategyHint）。
- `src/core/run.js`：`buildMission` に4枚目、案山子隊の生成（既存 formation を写して 0.7 倍）、決着で `training: true` のとき金・警戒度・略奪・遺物を飛ばし、戦死→負傷、戦功半分、忠誠 +2、`trainingCount`。`tallyBattleRecords` の `battles` は上限内のみ加算。
- `src/ui/ui.js`：カードの帯と「あと○回」、結果の文言。`src/data/mormo_lines.js` 2本。
- `src/ui/map.js`／`src/data/map.js`：訓練場の地点（絵が来たら）。
- `tools/test-training.js`（新）：死なない・金0・警戒0・戦闘数+1・上限4・宿舎 Lv2 と鍛冶場 Lv2 の効き。`tools/sim.js` に戦略「進軍の前に訓練を1回」と列「訓練回数」。
- battle.js：**触らない**（敵の HP・攻撃は run.js が写すときに落とす。戦死→負傷の変換は結果を読む側で）。

## 5. 決めてほしいこと（3つ）
1. 訓練で身につく上限は **4回／ラン**でよいか（3〜5 の間なら sim で詰める）。
2. 相手は「本戦の写し（予習）」でよいか。別案は「自軍の写し（鏡合わせ、自分の隊列の弱点が見える）」。予習の方が前哨戦と話が繋がるので、私は予習を推す。
3. 訓練でも**気合が貯まる**のは残すか。残すと「訓練→本戦で技連発」の流れができて気持ちいいが、強い。私は残す方（上限4回があるので暴れない）。
