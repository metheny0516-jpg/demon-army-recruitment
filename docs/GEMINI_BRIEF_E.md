## 世界観（1段落）

魔王軍の人事部が舞台。魔王はモンスターの履歴書を見て採用し、給料と食料を払い、
三部門（戦闘・生活・工作）へ配置し、王国へ攻め込む。モンスターは労働者で、
給料日・労災・有給・退職金の話をする。宰相モルモ（女の子、角あり）が魔王への報告役。
笑いの線は「魔界の日常に人間社会の職場あるあるを持ち込む」。血なまぐさくしない。

## これは何か

**戦闘と戦闘の間に1つだけ起きる事件**。魔王（プレイヤー）が選択肢を1つ選んで、軍の状態が変わる。
いま16本しかなく、10戦もすると全部見てしまう。**14本足して30本にしたい。**

## 絶対に守る3条件（これを外した案は採用できない）

1. **選択肢は2つ以上。** 「了解」を押すだけの通知イベントは作らない。
2. **選択肢のうち必ず1つは「得だが後で祟る」。** その場は明確に得をして、
   数戦あとに必ず跳ね返ってくるもの。祟りの中身まで書く。
3. **必ず下の「触れる資源」へ接続する。** 雰囲気だけで終わらせない。

## 形式（この形のブロックを14個、これ以外は出力しない）

```
### E01 タイトル（8文字以内）
- weight: 3   ← 出やすさ。ありふれた話は 4〜5、条件が厳しい話は 3
- いつ出るか: 食料が5未満で、生活部門に2体以上いるとき
- 登場人物: actor＝生活部門の誰か / other＝なし
- 本文:
  オーガが空の鍋を抱えて立っている。
  「メシ、無い。おれ、何を煮ればいい」
  厨房の床には、齧られた跡のある木のスプーンが落ちていた。
- 選択肢:
  1. 「備蓄を割って炊き出しをする」
     効果: 食料 -3、生活部門全員の忠誠 +10
     結果: 薄いスープが配られた。文句を言う者はいない。
  2. 「今日は我慢させる」（得だが後で祟る）
     効果: 食料の消費なし。actor の忠誠 -15、最大HP -10%
     祟り: 以後この者は不満側に回り、仲間割れ・ストライキの候補に入る
     結果: オーガは黙って鍋を伏せた。「……明日は、あるんだろうな」
```

## 書き方の注意

- **本文には登場人物の台詞を「」で1つ以上入れる。** 立ち絵と吹き出しに割る仕組みが既にあり、
  「」が無いとその者の顔が出ない。逆に「」さえ書けばコード側の変更は要らない。
- 本文は3〜5行。1行は40字以内。
- 効果は**必ず数値まで書く**（「忠誠が下がる」ではなく「忠誠 -15」）。
  そのまま実装できないと CodeX が数字を勝手に決めることになり、バランスが壊れる。
- 選択肢のラベルは魔王の命令口調。20字以内。
- 「得だが後で祟る」は14本すべてに1つずつ。**祟りの中身を必ず1行で書く。**
- 3択にしてよい。その場合「金貨を払って丸く収める」を混ぜると判断が濃くなる。

## 禁止

- 通知だけ（選択肢1つ）のイベント
- 上の「触れる資源」に無いものを増やす（新資源・新ステータス・新職業を発明しない）
- 既存16本と同じ題材
- 数字やゲーム用語を本文（地の文・台詞）に書く（「忠誠が下がった」等。効果欄にだけ書く）
- 血・拷問・差別的表現
- 全種族が同じ口調になる
