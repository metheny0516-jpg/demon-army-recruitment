# 設計案：華になる人間の剣士 ― 種族「堕騎士」（2026-09-14、Claude 起草。案。2026-09-15 オーナー：固有キャラではなく種族に、色白の美男子）

オーナー：「華となるイケメンキャラを作りたい。人間系で忠義のある剣士風。少しクセがありそうな」。

## 0. 一文で
**魔王軍に志願してきた人間の剣士。忠義は本物だが、忠義の相手が「魔王」ではなく「自分が決めた主」で、その主が誰かは本人しか知らない。**

## 0-2. 種族名の候補（オーナー「暗黒剣士でもなんでもいいが、そういうニュアンス」）

| 候補 | ニュアンス | 所感 |
|---|---|---|
| **堕騎士（だきし）** | 王に仕えることを自ら降りた騎士。「堕ちた」のは身分で、心ではない | 忠義とクセの両方が名前に入る。**推す** |
| 黒剣士 | 黒衣の剣士。中高生に一番通じる | 分かりやすいが、由来が無い |
| 魔剣士 | 魔に転じた剣士。魔法寄りに聞こえる | 剣士より術士に見える |
| 亡命剣士 | 国を捨てて来た。事情が伝わる | 少し説明的 |
| 夜剣士 | 夜に剣を振る。雰囲気だけ | 雰囲気はよいが意味が薄い |

→ 種族名は**堕騎士**、種族 id `fallen_knight`。応募者は複数いてよい（固有キャラではなく種族）。名前は応募者ごとに乱数（既存の名前生成に「堕騎士らしい名」の候補を10本足す：セシル、レオン、ヴァン、アルド、ユーグ、ノア、ジル、ラウル、エリオ、カイム）。

## 1. 人物（種族としての共通像）
- 名：**セシル・ヴァン**（仮）。二つ名候補「白刃」。王国の近衛だったが、王が不正を働いたのを見て剣を返し、魔王軍の門を叩いた。
- 見た目：**色白の美男子**（死霊術師と同じ「妙に写りがよい」系だが、あちらは病的で得意げ、こちらは**冷えていて静か**）。長い銀白の髪を片側に流し、黒と銀の軽鎧、赤い帯を一本。王国の紋を**自分で切り取った跡**が外套に残る。剣は一振り、鞘に布。目は細めない。表情は薄いが、口元だけ笑う。
- 話し方：丁寧で短い。魔王に対しても「陛下」ではなく「あなた」。モルモとは妙に馬が合う。
- クセ：**主と決めた相手の命令しか本気で聞かない**。採用直後は「あなた」＝魔王を主と認めていない。認めた瞬間から強くなる。

## 2. 遊び（今の仕組みだけで作る）
- **種族**（`MONSTER_TEMPLATES` に `fallen_knight`、tier 3、応募は征服度2以上、面接に並ぶ確率は低め）。人間だが魔王軍の種族の一つとして扱う。
- 戦闘：前衛、HP 中、攻撃 高、防御 中、速さ 高。種族技（3戦）**「抜刀」**：kind strike、power 1.4、必ず先に動く（order first）、気合1。上位技（8戦）**「一刀」**：kind execute（カタログ「とどめの見切り」）、HP 3割以下の敵を確殺、気合2。
- クセの中身＝**忠義の判定**：`loyalty` が 60 未満の間は「たたかう」の威力が 0.8 倍、種族技が出ない（「あなたの命令には、まだ」）。60 以上で通常、80 以上で「主と認めた」：全能力 +10%、台詞が変わる（「承知した、我が主」）。忠誠は今の仕組み（給与・酒場・引き留め）で上げる。**新しい数値は足さない**。
- 事件（噂の札に1枚）：忠誠 80 到達後、**王国から「戻れ」の使者**（B 自然発生）。関わらない→何も起きない。関わる→「断る」（忠誠 +10、以後王国の隊列に「元同僚」が出る）か「使者を斬る」（警戒度 +5、戦功 +3）。
- 大筋との繋がり：「引き抜き」（`BIG_ARCS` 1節）の**逆**。人間が魔王側に来た理由が、勇者戦の前に一言だけ語られる（「あの王に仕える勇者が、正しいとは思えない」）。

## 3. 絵（CodeX）
- 履歴書写真：`assets/monsters/fallen_knight.png`（768×1024、80KB以下）。証明写真なのに**視線を外している**（クセの表現）。
- 戦闘：`assets/battle/units/fallen_knight/` 6ポーズ＋review。抜刀の strike は居合の一線。
- イベント表情差分 3枚（`assets/monsters/events/fallen_knight/`：smirk / surprise / tears）。既存の種族と同じ規格。
- 画風は既存。色白の美男子だが**「よくある AI 美形」にしない**（原則13節）：死霊術師との描き分けは「病的で得意げ」対「冷えていて静か」。頬に古傷、外套はほつれ、視線は外す。
