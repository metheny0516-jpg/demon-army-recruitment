# 設計：勇者を退けたあと——三幕の構成（2026-09-11）

オーナー：「勇者退けたあとももちろんやりたい。新しい種族や技の追加も並行で」。
前提：今の20戦＝勇者戦はプロトタイプの着地（2026-09-10 決定）。確立後に中盤（新モンスター・新技・新敵）と終盤（クライマックス）を足して無料版完成。
勇者防衛戦までクリア済み（2026-09-11 試遊）。ここから先を決める。

## 0. 一文で

**勇者戦は終わりではなく幕切れ。** 王都を落としても勇者を退けても、王国は隣国に援軍を求め、第二幕が始まる。勇者は強くなって戻る。第三幕で決着。魔界史に刻むのは第三幕の結末だけ。

## 1. 三幕

| 幕 | 舞台（段階表） | 敵 | 着地 | 何が増えるか |
|---|---|---|---|---|
| 第一幕（今） | 村はずれ〜王都（段階1〜8） | 冒険者・傭兵・神殿騎士・王国軍・聖騎士団・勇者一行 | 王都攻略 か 勇者撃退 | ── |
| 第二幕「援軍」 | 隣国の国境〜連合軍の本陣（段階9〜14） | 隣国連合（重装歩兵・竜騎兵・砲兵）、聖教会（異端審問官・聖歌隊）、そして**成長した勇者一行**（新メンバー1人、段階14） | 連合本陣の陥落 か 勇者の再撃退 | 新種族3、上位技6、新しい作戦1（占領地の統治）、新しい事件 |
| 第三幕「決戦」 | 魔王城〜天界の門（段階15〜18） | 勇者の最終形（覚醒）、四天王級の敵将、最後は魔王城の最終防衛 | 勇者を討つ か 城を守り抜く → **エンディング**（魔界史） | 新種族2、上位技4、クライマックスの演出 |

- **どちらの着地からも次の幕へ**（第一幕の「攻めた／待った」の二本道はそのまま活きる）。攻めて落とした者は「王は隣国へ逃げた」、退けた者は「勇者は援軍を連れて戻る」。文が違うだけで、次の幕の入口は同じ。
- 幕の切り替えは決着の直後に一枚の場面（モルモの報告＋魔王の一言）。ランは続く。名簿・施設・蔵・伝承・魔王軍レベルは全部持ち越し。
- 魔界史に「第二幕まで」「第三幕で討った」が残る（記録の cause）。途中で全滅して名簿が空・金も無ければ今までどおり終わる。

## 2. 敵の成長との接続

- 段階表は一本に伸ばす（`ENEMY_STAGES` 18段）。`MAX_CONQUEST` は幕ごとに動く（第一幕 8、第二幕 14、第三幕 18）。「進軍」は幕の上限まで。
- 通常作戦の敵は征服度だけ（変えない）。反撃の討伐隊は魔王軍レベル基準（変えない）。**幕が進むと討伐隊の下限が上がる**（第二幕は段階9以上から来る）。
- 勇者の再来：第二幕の終わりは段階14で「勇者一行（再）」、第三幕の終わりは段階18で「勇者（覚醒）」。`checkCounterattack` の `hero` 判定を幕ごとの最終段階で見る。`heroCame` は幕ごとにリセット。

## 3. 内容の供給（並行できるもの）

**データだけで済み、CodeX の UI 作業と衝突しない**：`src/data/monsters.js` `traits.js` `enemies.js` `events.js`、絵は `assets/monsters/`。
- 新種族（第二幕3・第三幕2）：候補 サキュバス（魅惑・敵を惑わす後衛。オーナー指定）、ミノタウロス（前衛・突進）、リッチ（死霊の上位・術）、ガーゴイル（城の守り・留守番向き）、ドラゴンの仔（第三幕・成長する）。各種族に 1段目の技と上位技、癖の候補、履歴書の文（前職・志望動機・欠点・台詞）。
- 上位技は既存の形（`skill: { species, tier: 2, replaces }`、`order`、`autoLimit`）で。
- 敵は段階表の行を足すだけ（名前・数値・variants）。敵にも**一癖**（弓兵は後列を狙う、審問官は技を封じる、砲兵は全体）を `traits` で持たせる——これは battle.js に敵用の特性フックが要るので、**別仕様**（`SPEC_ENEMY_TRAITS`）。まずは数値と隊列の癖（variants）だけで作る。
- 絵：オーナーが描く（Photoshop）。無い間は既存のフォールバック（種族の絵が無ければ既定の影）で動かす。

## 4. 進め方

1. **データ供給を先に**（Opus）：`docs/SPEC_ACT2_CONTENT_2026-09-11.md`。新種族3＋上位技6＋敵段階9〜14。今の第一幕の中では**まだ出ない**（tier 4 として応募に混ざらない）。テストとデータだけ。
2. **幕の進行**（Claude が仕様化、Opus か CodeX が実装）：`st.act`、`MAX_CONQUEST` の幕ごとの上限、勇者戦後の切り替え場面、討伐隊の下限、応募の tier 解禁。run.js。**CodeX の城のメニューが入ってから**（UI の衝突を避ける）。
3. 第三幕は第二幕を試遊してから。
