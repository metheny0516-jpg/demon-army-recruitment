# 提案：カタログ25本の技を「誰に・いつ」（2026-09-13、Claude。オーナー判断待ち）

`src/data/skills_catalog.js` の25本（CodeX 作。5本は痕跡から派生）は、効きは実装済みだが**誰も持っていない**。
ここでは全部を使い切ろうとしない。**上位技が無い8種族に1本ずつ**、**痕跡に5本**、**敵の役に6本**、残り6本は倉庫。

判断の物差し：「その種族らしいか」「一文で言えるか」「既存の技と役目が被らないか」。数字（気合・倍率）はカタログのまま。

## 1. 上位技（8戦目）が無い8種族へ 1本ずつ

| 種族 | 種族技（3戦） | 上位技の案（カタログから） | 一文 | なぜ |

| スライム | 粘りつく（拘束） | **臨時分身** `summon_minion` | 自分の欠片を1体呼ぶ | スライムは増えるもの。キングスライム合体とも話が繋がる |
| 骸骨兵 | 骨の壁（かばう） | **総員防壁** `wall_all` | 味方全員に一度だけ盾 | 盾役の完成形。かばうの上位として素直 |
| ゾンビ | 腐敗の一噛み（弱体） | **吸い上げ** `drain` | 噛んで自分が回復 | 「死んでるのに食う」がゾンビらしい |

- 種族技の3戦と同じく、研究所 Lv3 で -2 戦。

## 2. 痕跡（traces）由来の5本 → 痕跡そのものに付ける

`弔い合戦 mourning`／`担がれの恩 carried_debt`／`常連の勘 veteran`／`遺物の重み relic_weight`／`担がれた者の盾 carried_resolve`。
これは設計どおり**種族ではなく経歴**で開く技。担がれて帰った者・戦友を失った者・古株・遺物持ちが、その戦いの窓に1本余分に持つ。
- 条件は run.js が `m.skills` に足す／消す（`options.traces` は既にある）。担当は Opus（統合が終わってから。仕様は別紙で1枚）。
- 気合コストはカタログのまま。数が増えすぎないよう**同時に持てる痕跡技は1本**（条件が複数なら古い方）。
