## 2. 実装で直すこと（文章は変えない）
- 「なぜ」欄の型「{痕跡1の本人名と出来事}と{痕跡2の本人名と出来事}がこの話につながった。{状態}は{実値}だったため、{今回の出来事}になった」は長い。**2文に分ける**：「火の粉を浴びたプル、大食いのプル。」「スライムが2体いたので、分身を連れ帰った。」
- 「別枝の結果」「別枝のモルモ」は全札で用意されているので、データは `branches: { yes: {text, mormo}, no: {text, mormo} }` の形で持つ。
