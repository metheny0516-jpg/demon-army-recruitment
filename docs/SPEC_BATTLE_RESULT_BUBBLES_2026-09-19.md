# 戦場に残る戦果と本人の吹き出し

## 目的
戦果を「誰が何を得たか」で読めるようにする。既存の戦闘・成長・給与・報酬計算を変更しない。

## 表示順
1. 既存の決着表示とファンファーレ。
2. 生存し、負傷・稽古での戦闘不能が記録されていない参加者から、既存の戦後台詞を対象者それぞれ一人ずつ。確定済みの contribution.voice をそのまま使う。
3. 成長した人物ごとに「HPが1アップ、攻撃が2アップ！」。lastGrowth の実値を使い、同じ人の伸びをまとめる。
4. 習得技ごとに「《技名》を覚えた！」。新技の見出しで強調。
5. 獲得報酬と戦利金。稽古・撤退・敗北は対応する表現。

戦場の本人に吹き出しを出し、戦場直下にも名前付きの一行を表示する。戦場に見つからない人物の成長は一行で伝える。名寄せは既存レンダラの名前契約（同名は生成時に防ぐ）に従う。

通常の一言は2.4秒、新技は3秒で自動送り。戦場タップか「次のひとこと」で送れる。「最後まで飛ばす」で発表を終了し、「結果を見る」は発表途中でも使える。結果一覧は成長を全件、最初から表示する。ロード後は既存の結果一覧で確認できる。

戦闘不能時は味方一人につき一戦一度、既存の本人の種族の voices.dead から一言。「遺書」は代表例であり共通台詞ではない。台詞がない種族には追加しない。描画用の抽選はゲーム用乱数を消費しない。永久戦死と召喚ユニットには出さない。蘇生で発話済みをリセットしない。

## 実装境界
UI.battle / battleManual の再生終了コールバックから開始する。読み上げは確定済み lastBattle / lastGrowth のみを読み、ゲーム状態を書き換えない。画面離脱時の BattleScene.stop で読み上げタイマー・吹き出し・ボタンを掃除する。戦闘スキップ後の演出タイマー契約と分ける。低モーション時は既存吹き出しCSSの静止表示を使い、同じ読書時間と手動送りを残す。

## 受け入れ確認
- 本人と数値・技名が一致し、成長を二重適用しない。
- 同じ人の複数成長が一度に分かる。技は独立表示。
- スキップ・画面移動後に古い発話が割り込まない。
- 死者が勝利後に喋らない。戦闘不能は一戦一度、永久戦死では冗談を出さない。
- 390px・PC・低モーションで一行表示と送り操作を確認する。
- ブラウザ battle-result-bubbles を run-all に登録。本線取り込み前に全回帰を通す。


## 2026-09-20 オーナー指定：クリック送り

戦後の一言・能力成長・技習得・報酬は自動で送らない。タップ／クリックまたは「次へ」で一行ずつ進む。
戦闘の自動指示・x2・x4に関係なく待つ。「結果を見る」で残りを飛ばせ、結果画面で全件確認できる。
順序は一人ごとに一言→成長→新技、最後に報酬。該当しない項目は省く。前節の自動送り記述よりこの指定を優先。
