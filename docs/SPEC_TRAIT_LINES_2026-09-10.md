## 2. 背景（なぜ台詞なのか）

この特性群は「数値ではなく出来事の順番に効く」。酒好きは攻撃力ではなく**遅刻**、大食漢はHPではなく**倒した相手の携行食を食べて次の手番を飛ばす**、改造癖は効率ではなく**任せた糧食が樽で発酵して誰かが酔う**。
オーナー試遊の評価：「意外性に虚を突かれた感じだが悪くない」「表示（戦闘中に止まって状況説明）はすごく良くなった」「いろんなバリエーションを見たい」。
同時に出た注意：大食漢が人間相手に「弁当だ、悪いな」と食べ始めるのは**グロテスクに読めた**。以後、食べる対象は必ず**物**（弁当・干し肉・パン・チーズ・酒・水筒）を出す。

台詞の判定基準は3つ（オーナーの言葉）：
1. 一回見たときに、何が起きたかすぐ分かるか
2. 二回目に「また来るかも」と少し期待するか
3. ただの面倒ではなく、人物として面白いか

### 3.2 説明文の修正

`TRAITS.tinkerer.desc` の「生活部門に置くと」を「留守番にいると」に直す。部門は「出撃隊」と「留守番」の二つになった（HANDOFF §0）。他の `desc` に「部門」が残っていれば同様に直す（`grep -n 部門 src/data/traits.js`）。

### 3.3 台詞の書き方（守ること）

- **人物ごとの脚本は書かない**。`{name}` `{by}` 以外の固有名詞を入れない。特定のオークの名前・過去は出さない。
- **一行は全角28文字以内**。下半分の一言枠（`mormo-aside`）で1〜2行に収まる長さ。
- **数値を言わない**。「+25%」「HPが」「ダメージ」は禁止。出来事だけを言う。
- モルモ口調：語尾「デス」「マス」。魔王を「魔王様」。丁寧だが慌てている。既存3行の調子に合わせる。
- 本人口調：種族で変えない（オークもコボルトも同じプールを引く）。短く、ぶっきらぼう。既存の「待たせたな」「……で、どいつを殴ればいい」の調子。
- 大食漢の `eat`：**毎行に物を出す**。使ってよい語：弁当・握り飯・干し肉・パン・チーズ・酒・水筒・林檎・携行食・干し魚・塩漬け・堅パン。「こいつ」「相手」だけで終わる行は不可。「食う」の目的語が人に読める行は不可（「こいつを食う」×、「こいつの弁当を食う」○）。
- 改造癖の `absent`：`{by}` は**戦場に居ない人物**。「{by}殿も来ていません」のような、居るように読める表現は不可。
- 同じ意味の言い換えを並べない。8本なら8つの違う状況（一杯だけのつもり／誰かに止められた／二日酔い／賭け事で負けた／寝坊／道に迷った…）。**状況の違い**が「二回目の期待」を作る。
- ギャグは軽く。下品な語（排泄・性的）は不可。

### 3.4 候補特性2つ（データのみ、ロジック無し）

次に実装する候補として、`TRAITS` に2つ足す。**フック関数（`modDealt` 等）は一切書かない**。`proposed: true` を付ける。既存コードは未知のフィールドを無視するので、足しても挙動は変わらない。`monsters.js` の `traitPool` / `fixedTraits` には**入れない**（入れなければ誰にも付かず、ゲームに現れない）。

```js
  // 候補。ロジック未実装（proposed）。付与もされない。台詞と「何が起きるか」の言葉だけを先に用意する。
  timid: {
    name: "怖がり",
    proposed: true,
    desc: "味方が倒れると逃げ出そうとする。誰かが引き留めれば踏みとどまる",
    // 出来事の案（設計担当が後で仕様にする。ここは実装しない）：
    //   味方が初めて倒れたラウンド末に「逃げそう」になる。同じ側に《忠犬》か将軍がいれば引き留められて留まる。
    //   誰もいなければ次のラウンドは動かない（逃げかけて戻ってくる）。数値は変えない。
    lines: {
      flinch: [ /* 逃げそうになったとき本人 6本以上 */ ],
      held:   [ /* 引き留められたとき、引き留めた側の一言 6本以上。{by} = 引き留めた者 */ ],
      back:   [ /* 戻ってきたとき本人 6本以上 */ ]
    }
  },
  show_off: {
    name: "見栄っ張り",
    proposed: true,
    desc: "開戦時、勝手に最前列へ出る。並びが崩れる",
    // 出来事の案：開戦時に配置順を無視して先頭に立つ（狙われやすい）。モルモが一言。
    lines: {
      front: [ /* 前へ出るとき本人 6本以上 */ ],
      mormo: [ /* モルモ 4本以上。{name} */ ]
    }
  },
```

名前・説明・出来事の案は変えてよい（もっと面白い癖があれば置き換える）。ただし条件は同じ：**数値に効かず、出来事の順番に効く**こと、台詞だけで何が起きたか分かること、`coward`（卑怯者。既存の数値特性）と被らないこと。
